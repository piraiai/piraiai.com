What Pirai AI Preserves

Matrix questions. A matrix question in your Word document - where multiple statements share the same rating scale - is converted to a Multiple Choice Grid question in Google Forms. The row statements and column scale labels are preserved exactly as written in your source document. For a 20-item Likert battery, this saves the manual creation of 20 separate questions and keeps the visual matrix format that respondents expect.

Likert scales. Single Likert items are converted to Linear Scale questions with the correct numeric range and custom endpoint labels (e.g. "Strongly Disagree" to "Strongly Agree"). Batteries of Likert items sharing the same scale are converted to Multiple Choice Grid questions for efficient display. The scale labels are pulled from the source document, not guessed.

Branching logic. Skip logic and display logic in your survey document is converted to Google Forms section-based routing. Each branch path becomes a section, and the routing condition is set at the question level. Google Forms supports one level of branching per question - complex nested logic is flagged in the output for manual configuration in the Form editor after the script runs.

Recode values and question IDs. Numeric recode values assigned to answer options in your source document are preserved in the script for reference, even though Google Forms does not display recode values to respondents. Question IDs from the source document are carried through as comments in the script, making it easier to cross-reference the Google Form against your original survey specification.

Frequently Asked Questions

Does Google Forms support matrix questions?+

Yes, through the Multiple Choice Grid and Checkbox Grid question types. These display multiple row statements against a shared set of column options in a grid format. Pirai AI maps matrix questions from your source document to the appropriate Grid question type in the generated Apps Script.

Will branching logic survive the conversion to Google Forms?+

Section-based branching logic is converted to Google Forms section routing. Google Forms supports one level of conditional section branching - if answer X, go to section Y. More complex nested logic is flagged for manual configuration in the Form editor after the script runs.

Does Pirai AI need access to my Google Drive?+

No. Pirai AI generates a Google Apps Script file you download and run yourself inside your own Google Form. No OAuth connection, no Drive permissions, no third-party access to your account at any point.

What happens to my survey document after conversion?+

Your document is processed entirely in-memory and destroyed after the Apps Script is generated. No file is stored on Pirai AI's servers. OpenAI API training controls are disabled so your document content is not used for model training.

Can I convert a Qualtrics QSF file to Google Forms?+

Yes. Upload the QSF file directly to Pirai AI and select Google Forms as the target. Qualtrics question types are mapped to the closest Google Forms equivalents. Note that Qualtrics-specific features like embedded data, quotas, and advanced display logic do not have direct equivalents in Google Forms and are noted in the output.
