What Embedded Data Is

Embedded data in Qualtrics is information stored alongside survey responses that is not collected through visible survey questions. It is set up in the Survey Flow and populated from URL parameters, XM Directory contact attributes, default values, or calculated values assigned during the survey. It enables personalisation, routing, and segmentation without asking respondents to report information you already know.

How Embedded Data Works

Embedded data fields are created in the Survey Flow, which controls the order and conditions under which elements in your survey execute. Each embedded data element specifies a field name and where its value comes from. The value is then stored in the response data alongside question answers - invisible to respondents but fully accessible in data exports, dashboards, and workflows.

You can insert embedded data values into question text, answer options, and email messages using Piped Text syntax: ${e://Field/FieldName}. This enables personalised survey experiences - addressing respondents by name, referencing their recent purchase, or displaying their account tier - without storing that information in visible questions.

The Four Sources of Embedded Data Values

1. URL parameters. The most common source. Append field names and values to the survey link: your-survey-link?CustomerID=12345&Region=North. In Survey Flow, create an Embedded Data element with field names matching the URL parameter names. When the survey is opened via the parameterised link, the values populate automatically. Use this to pass CRM data, panel member IDs, source tracking codes, and campaign identifiers into survey responses.

2. XM Directory contact attributes. When surveys are distributed via Qualtrics XM Directory (Contacts), the contact's profile attributes can be pulled directly into embedded data. Create the embedded data element in Survey Flow with the field name matching the XM Directory contact attribute name. The contact's specific attribute value populates without any URL parameter needed. See the XM Directory Mapper for extracting and documenting these field mappings across environments.

3. Default / static values. Set a fixed default value in the embedded data element. Use for survey wave tracking (Wave = "Q3 2026"), survey version tracking (Version = "B"), or source identification when a survey is distributed through a single known channel.

4. Values set by logic or scoring. Embedded data values can be assigned conditionally using Branch Logic in Survey Flow - "If Q3 = Yes, set CustomerSegment = 'High Risk'." They can also receive calculated scoring values from the Qualtrics Scoring feature, enabling composite risk scores, satisfaction categories, or segment labels to be stored as embedded data for downstream routing and reporting.

Common Embedded Data Use Cases

Respondent Identification

Pass Customer ID, Employee ID, or Contact ID via URL parameter to link responses to CRM or HRIS records without asking respondents for their identifier.

Source Tracking

Track which email campaign, in-app trigger, or QR code generated each response. Set Source = "Q3_Email" or Source = "InApp_Trigger" per distribution channel.

Personalisation

Display the respondent's first name in the survey header: "Hi ${e://Field/FirstName}, we'd like your feedback." Pulled from XM Directory contact or URL parameter.

Conditional Routing

Route respondents to different question blocks based on their CRM segment without asking them which segment they belong to. Embed the segment value and use it in display logic or branch logic.

Segment Analysis

Pre-populate respondent tier, product, region, or cohort so that dashboard filters and cross-tabulations work without manual data joining post-collection.

Workflow Triggers

Store calculated scores or flags as embedded data to trigger Qualtrics Workflows - alert a case manager when a risk score exceeds a threshold, or update the XM Directory contact when a satisfaction flag is set.

Frequently Asked Questions

How do I set up embedded data in Qualtrics?+

Open Survey Flow from the Survey tab. Click 'Add a New Element Here' and select 'Embedded Data.' Enter the field name. To populate from URL parameters, leave the value blank - it will be populated from the URL when the survey opens. To set a default value, type it in the Value field. Place the Embedded Data element at the top of Survey Flow so it is set before any questions reference it.

What is the difference between embedded data and survey questions?+

Survey questions are visible to respondents and collect information through their answers. Embedded data fields are invisible to respondents and store information populated from external sources (URL parameters, XM Directory) or calculated during the survey. Both are stored in the response data but serve different purposes.

How do I use embedded data values in Qualtrics question text?+

Use Piped Text syntax: ${e://Field/FieldName} - where FieldName is the name of your embedded data field. Paste this into question text, answer options, or email message content. When the survey runs, the placeholder is replaced with the actual embedded data value for each respondent.
