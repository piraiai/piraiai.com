How Microsoft Forms Quick Import Works

Microsoft Forms' Quick Import reads questions from a structured document and creates the questions in a new form automatically. Access it from the form editor by clicking the three-dot menu (top right) and selecting Import questions from Word. The import reads a formatted Word document structure.

Pirai AI produces the correctly structured output from your source document - regardless of whether your source is a PDF, Excel file, or existing Word document in a non-import-ready format. The output is formatted to what MS Forms Quick Import expects.

Matrix Grid Questions: What to Expect

Microsoft Forms does not support matrix grid questions through Quick Import. A matrix question with 8 items rated on a 5-point scale cannot be imported as a single grid - Microsoft Forms would require 8 separate questions.

Pirai AI handles this automatically: each row of the matrix becomes an individual Choice question with the same scale options as the matrix columns. Your 8-item matrix becomes 8 Choice questions - every item is preserved, just as individual questions rather than a grid. You can optionally merge them into a Likert native question type in the MS Forms editor after import.

Why Microsoft Forms in an M365 Environment

For organisations on Microsoft 365, Microsoft Forms has integration advantages that Google Forms cannot match: responses write directly to SharePoint lists; Power BI connects natively to Forms response data; forms can be embedded in Teams channels, SharePoint pages, and Viva Engage; and responses are governed by your tenant's compliance and data residency policies, not Google's.

For HR teams using Word to draft survey templates and then deploying in an M365 environment, Pirai AI removes the manual re-entry step between the Word document and the live Microsoft Form.

Frequently Asked Questions

How do I import a Word document into Microsoft Forms?+

Microsoft Forms supports Quick Import from the form editor - click the three-dot menu (top right) and select Import questions from Word. The Word document must be structured in a specific way. Pirai AI produces a correctly structured output from any source document (Word, PDF, or Excel) that is ready for MS Forms Quick Import.

Does Microsoft Forms support matrix grid questions?+

Microsoft Forms does not support matrix grid questions via Quick Import. Pirai AI expands matrix questions into individual Choice questions automatically during conversion - so no question is lost, but the visual grid format is not preserved. You can optionally reconstruct the grid as a Likert question type in the MS Forms editor after import.

What is the difference between Microsoft Forms and Google Forms?+

Both are free form builders with basic survey functionality. Microsoft Forms integrates with M365 (SharePoint, Teams, Power BI, data residency policies), while Google Forms integrates with Google Workspace (Sheets, Drive). Microsoft Forms has native NPS, Ranking, and Likert question types. Google Forms has wider anonymous respondent accessibility. See the full comparison at /blog/google-forms-vs-microsoft-forms.

Yes. Upload your survey document to Pirai AI and export to Microsoft Forms for your M365 users and to Google Forms for external respondents or users without Microsoft accounts. Both outputs come from the same source document with identical question wording.
