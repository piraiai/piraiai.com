Overview

How Pirai AI Flow works

Open Flow on any Qualtrics dashboard page. Describe what you want in plain English. Flow reads your dashboard's real fields and builds the widget instantly, with no menus and no manual field mapping.

  • Use @fieldId to reference a specific field (e.g. @DM_rawhzhd)
  • Or describe the field in plain English and Flow will find the closest match
  • Simple prompts give you just enough to create the widget quickly
  • Detailed prompts include title, description, labels, and formatting options

Before you start

Click Reload in Flow after making changes in Qualtrics directly. Flow reads your dashboard's live field list on every reload. The more specific your field reference, the more accurate the result.

Number Chart

Displays a single large metric: count, average, NPS, or top box. The headline widget on most executive dashboards. Supports period-over-period change comparison.

Quick create
Number Chart count

Quickest way to add a response count to your page.

Count

Pattern: Number Chart count
Number Chart count

Creates a Number Chart showing the total count of responses. Flow picks a sensible title automatically.

Count with title and options

Number Chart count, title as Response Count, description as Displays the total count of responses, count metric label as Response Count, show response count, enable change since
  • title as Response Count sets the widget heading
  • description as... adds a subtitle below the title
  • count metric label labels the metric value
  • show response count displays the number of responses
  • enable change since adds a period-over-period comparison arrow

Average metric

Number Chart average @DM_rawhzhd, title as Average Sat, description as Displays the Average Sat, avg metric label as Average Sat, show response count, enable change since
  • average @DM_rawhzhd calculates the average of that specific field
  • avg metric label labels the value shown in the widget
  • show response count displays the response count below the metric
  • enable change since shows how the metric changed vs the previous period

Supported options

metric function (count / average / sum / NPS / top box), title, description, metric label, metric format, decimals, show response count, enable/disable change since.

Record Table

Lists individual response records as rows with chosen fields as columns. Does not aggregate. Shows raw, individual responses. Use @fieldId to specify columns.

Quick create
Record Table with @fieldId1 @fieldId2 @fieldId3

Replace with the fields you want as columns. Any field type works.

Multi-column record table

Record Table with @startDate @status @DM_7ksz3zx with the title Response Records, show response count, add description Responses record

Creates a record table with three columns: start date, response status, and the satisfaction field. Each row is one individual response.

Full record view

Once a Record Table is created, you can enable full record view to let viewers click a row and see all fields for that response: "Enable full record view on [Response Records], 2-column layout. Satisfaction Score on the left, Open Feedback on the right."

Tips & Best Practices

Referencing fields

  • Use @fieldId for an exact field match, e.g. @DM_rawhzhd or @QID6_TEXT
  • Or describe the field in plain English and Flow will find the closest match from your dashboard's field list
  • Wrap widget names in square brackets when updating, e.g. [Response Records]

Updating existing widgets

  • Change a metric: "Change the metric on [Average Sat] to NPS"
  • Relabel a column: "Change the label on [Response Records] column @QID6_TEXT to Staff Name"
  • Enable full record view: "Enable full record view on [Response Records]"
  • Switch an axis: "Change the x-axis on [Count by State] to Location"

Multi-widget and group creation

  • Create multiple at once: "Create a Number Chart count and a Gauge Chart average satisfaction"
  • Create a group: "Create a group with a Gauge Chart NPS, Number Chart response count, and a Vertical bars by channel"

Field types matter

  • Metrics (average, sum, NPS, top box) require a Number Set or Numeric Value field
  • Axes and dimensions require a Text Set, Multi-Answer Text Set, Number Set, or Date field
  • Word Cloud and Response Ticker require an Open Text field only
  • Star Rating requires a Number Set field only
