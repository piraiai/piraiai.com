Qualtrics Field Types

Every field in a Qualtrics dashboard has an internal type that determines which widgets it can power. Flow uses these types automatically when mapping your fields to widget configuration.

Qualtrics Name Internal Type
Numeric Value
Continuous data — 0 to infinity
ScalarValue
Used for avg, sum, min, max metrics
Number Set
Discrete numeric — e.g. Likert scales
EnumerableScalarValue
Used for avg, NPS, top box, Star Rating
Date
Calendar date and time
DateTime
Used as axis/dimension with groupBy (day, month, quarter, year)
Text Set
Limited set of text values — e.g. Agree/Disagree
EnumerableValue
Used as axis/dimension and filters
Multi-Answer Text Set
Multiple text values per response
EnumerableValueSet
Used as axis/dimension and filters
Open Text
Long open-ended text responses
FreeFormText
Required for Word Cloud and Response Ticker
Text Value
Short open text — e.g. name, email
GenericValue
Record Table columns and filters only
