Quick Answer

Google Forms does not have a native matrix question type but supports two built-in workarounds: Multiple Choice Grid (single select per row) and Checkbox Grid (multi-select per row). For a complex survey document, Pirai AI converts matrix questions automatically to the correct Grid type via Google Apps Script with no Drive access required.

What a Matrix Question Is

A matrix question presents multiple row statements rated against the same set of column options - typically a Likert scale. A customer satisfaction matrix might ask respondents to rate "Speed of service," "Quality of product," and "Staff helpfulness" each on a scale of "Very Poor" to "Excellent." In professional survey platforms like Qualtrics, this is a single Matrix Table question. In Google Forms, it requires workarounds.

Three Methods for Matrix Questions in Google Forms

1
Multiple Choice Grid
Built-in

Google Forms' native closest equivalent to a matrix question. Each row is a statement; each column is a scale point. Respondents select one option per row.

How to add it: Click the + button to add a question. Click the question type dropdown and select Multiple choice grid. Add your row statements (the items being rated) and column headers (the scale points, e.g. 1-5 or Strongly Disagree to Strongly Agree).

  • Enable "Require a response in each row" to force all items to be rated
  • Enable "Limit to one response per column" for rank-style grids where the same value cannot be selected twice
  • Columns are limited to 5 in the Google Forms mobile app - keep scale points to 5 or fewer for mobile respondents
Limitation: Respondents can select only one option per row. For multi-select matrix questions, use Checkbox Grid instead.
2
Checkbox Grid
Built-in

The multi-select version of Multiple Choice Grid. Allows respondents to select multiple options per row. Use for questions where more than one answer per item is valid.

How to add it: Same as Multiple Choice Grid but select Checkbox grid from the question type dropdown. Useful for "select all that apply" style matrices or attribute association questions.

Limitation: Neither grid type supports a "Not applicable" column that spans the full row. If you need N/A as a response option, add it as an additional column - but note this breaks the visual symmetry of a rating scale.

Google Forms Matrix Limitations to Know

Google Forms grid questions have real limitations compared to dedicated survey platforms. There is no option to randomise row order within a grid, which matters for research surveys where item order effects are a concern. There is no way to add explanatory text between matrix rows. The grid cannot display images or formatted text in row labels. And on mobile, grids with more than five columns render poorly - respondents must scroll horizontally to see all scale points.

For research surveys where these limitations are problematic, Qualtrics or REDCap provide full matrix functionality. Pirai AI converts your document to those platforms equally well - select a different target platform in the same conversion session.

Frequently Asked Questions

Does Google Forms have a matrix question type?+

Not by that name. Google Forms has Multiple Choice Grid (single select per row) and Checkbox Grid (multi-select per row), which function as matrix questions. These are the closest equivalents to the Matrix Table question type in Qualtrics or the radio button grid in REDCap.

How many rows and columns can a Google Forms grid have?+

Google Forms does not publish a hard limit on rows, but grids with more than 10 rows become unwieldy on mobile. Columns are displayed well up to 5 on mobile; more than 5 requires horizontal scrolling on smaller screens. For large matrix batteries, consider splitting into multiple shorter grids.

Can I randomise row order in a Google Forms grid?+

No. Google Forms does not support randomisation of row order within a grid question. If row order randomisation is required for your research design, consider using Qualtrics or another platform that supports this feature. Pirai AI converts your survey document to Qualtrics equally well.
