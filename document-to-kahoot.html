Why You Can't Import a PDF or Word Doc Directly into Kahoot

Kahoot's import function accepts one specific format: an Excel spreadsheet (.xlsx) structured to Kahoot's template. Questions, answer options, correct answers, and time limits must be in the correct columns. On top of that, Kahoot enforces strict character limits - 95 characters per question and 60 characters per answer - that cause import errors when exceeded.

This means a 40-question quiz sitting in a Word document or PDF cannot be imported into Kahoot directly. It must be reformatted into the Kahoot spreadsheet template first. Doing this manually for every question - checking character counts, assigning correct answers, populating four columns per question - takes 30-60 minutes for a typical classroom quiz.

Frequently Asked Questions

What format does Kahoot import quizzes in?+

Kahoot imports quizzes from an Excel spreadsheet (.xlsx) formatted to Kahoot's template. The spreadsheet must have columns for question text, up to four answer options, a time limit, and the correct answer number. Kahoot does not import Word documents, PDFs, or plain text files directly.

How do I convert a Word quiz to Kahoot?+

Upload your Word (.docx) file to platform.piraiai.com and select Kahoot as the target platform. Pirai AI extracts all questions and answer options, formats them to Kahoot's spreadsheet template, and produces a .xlsx file ready for import. In Kahoot, go to Create > Quiz > Blank Canvas > Import spreadsheet to upload the file.

Does Pirai AI handle Kahoot's 95-character question limit?+

Yes. Pirai AI respects Kahoot's character limits - 95 characters for questions and 60 characters for answers - when formatting the import spreadsheet. Questions or answers that exceed these limits are flagged in the AI Survey Editor for review before the spreadsheet is downloaded.

Can I also convert the same document to Google Forms or Qualtrics?+

Yes. From the same document upload, select a different target platform. Pirai AI converts to Google Forms, Qualtrics, REDCap, SurveyMonkey, and 23 more platforms from the same structured extraction. This is useful for teachers who need the same quiz on both Kahoot and Google Forms.
