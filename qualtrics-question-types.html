Overview

Qualtrics supports 20+ question types across six categories: multiple choice and selection, text entry, matrix and rating, scale and slider, speciality types, and structural elements. Understanding which type to use - and when Qualtrics' native types outperform Google Forms or SurveyMonkey equivalents - is the foundation of professional survey design in Qualtrics.

Multiple Choice and Selection Types

Multiple Choice (Single Answer). The standard single-select question. Renders as radio buttons by default. Configure as a dropdown or as a horizontal row in advanced display settings. Use for categorical questions with mutually exclusive options. Can trigger display logic conditions or skip logic based on the selected choice.

Multiple Choice (Multiple Answer). Checkboxes allowing any number of selections. Add "Force Response" to require at least one selection, or use "Min/Max Choices" validation to constrain the number of options selected. Exports each option as a separate binary variable (0/1), which is important for data analysis planning.

Dropdown. Single-select displayed as a dropdown menu. Best for long option lists (20+ items like countries, states, or departments) where radio buttons would take excessive vertical space. Cannot trigger skip logic - use Multiple Choice if the answer needs to route respondents to different sections.

Drill Down. Cascading dropdowns where the second selection depends on the first. Example: select Region, then State within that Region, then City within that State. Configured using a hierarchical data file. Useful for geographic selection, product category trees, or any hierarchical classification.

Image Select (Graphic Rating). Respondents select from images rather than text options. Use for packaging tests, ad creative evaluation, logo selection, and any stimulus-response question where the option is visual rather than textual.

Text Entry Types

Text Entry (Single Line). A single-line text field for short responses. Add validation for content type (email, phone, number, date, URL, custom regex) under "Content Validation." Use for names, email addresses, ID fields, and numeric responses requiring format validation.

Text Entry (Multi-Line / Essay). A multi-line text area for longer open-text responses. Use for NPS follow-up questions, open feedback, and qualitative responses. Set a character minimum or maximum under validation to guide response length.

Form Field. A multi-field form within a single question - collects name, company, email, and phone number in one block. Useful for lead generation surveys and registration forms where multiple contact details are needed together.

Matrix and Rating Types

Matrix / Rating Scale. The most-used question type in professional surveys. Multiple row statements rated on a shared column scale. Configure as Likert (Strongly Disagree to Strongly Agree), as a frequency scale (Never to Always), as a satisfaction scale, or with custom scale labels. Add row randomisation to counteract order effects. Carry-forward allows selected rows to populate a follow-up question automatically.

Bipolar Matrix. A Matrix question where each column header is a bipolar adjective pair (Fast/Slow, Modern/Traditional) rather than a unipolar scale. Used for semantic differential measurement in brand perception and attitude research.

Side by Side. Presents multiple matrix sub-questions side by side in columns, all sharing the same row list. Example: rate each product on Quality, Value, and Likelihood to Recommend in a single compact grid. Reduces page length for complex multi-attribute ratings.

Constant Sum. Respondents distribute a fixed total (100 points, a budget amount) across a list of options. Available as dropdown, slider, or text entry formats. Used for share-of-wallet studies, feature prioritisation research, and budget allocation exercises.

Scale and Slider Types

Net Promoter Score (NPS). Native NPS question type with the 0-10 scale pre-configured with correct labelling ("Not at all likely" / "Extremely likely"). Automatically calculates Promoter, Passive, and Detractor groups for dashboard widgets. Always use the native NPS type rather than a manually configured scale - it integrates with Qualtrics CX dashboards and ensures consistent benchmark data.

Slider. A drag-to-rate interface. Available as Bar Slider (horizontal range), Grid Slider, Star Rating, and Smiley Face variants. Use for continuous rating data where the visual drag interaction increases engagement. The Grid Slider allows multiple items to be rated simultaneously on a shared axis.

Specialty Types

Rank Order. Respondents rank items by preference or importance. Available as drag-and-drop (most intuitive), dropdown (most accessible for AT users), radio button (forces sequential selection), and text box formats. For more than 7-8 items, drag-and-drop becomes unwieldy - consider a top-N format ("rank your top 3") or use MaxDiff instead.

Pick, Group, and Rank. An advanced sorting question where respondents categorise items into groups and optionally rank within groups. Used for card sorting research, priority mapping, and audience segmentation exercises.

Heat Map. Respondents click on a region of an image to indicate attention, preference, or location. Used for packaging research (eye-tracking simulation), website usability testing, and ad creative evaluation.

Hotspot. Similar to Heat Map but uses predefined clickable regions rather than freehand clicking. Use when you want to measure clicks on specific labelled zones of an image.

Signature. Captures a handwritten electronic signature. Used for consent forms, approval workflows, and applications requiring a personal signature.

File Upload. Allows respondents to upload files (images, PDFs, documents). Use for evidence submission, portfolio collection, or receipt upload in incentivised surveys. Files upload to Qualtrics storage and are accessible in the survey response data.

Captcha Verification. A reCAPTCHA challenge placed at the beginning of a survey to filter bot responses. Particularly useful for surveys distributed via open public links on panels with high bot traffic risk.

Timing. Not a standalone question type but a meta-question that records how long a respondent spent on a page. Added to any page to measure engagement and detect suspiciously fast responses. Used in data quality analysis post-fieldwork.

Structural Elements

Descriptive Text / Display Block. A text-only element with no response field. Use for survey section headers, instructions, informed consent text, and explanatory copy between questions. Supports rich text formatting, images, and embedded media.

Page Break. Forces a new page in the survey. Controls which questions appear together on a single page. Important for surveys where page timing is recorded - each page break creates a distinct timed segment.

Frequently Asked Questions

How many question types does Qualtrics have?+

Qualtrics has 20+ question types including Multiple Choice, Matrix/Rating Scale, NPS, Rank Order, Constant Sum, Side by Side, Slider, Drill Down, Heat Map, Hotspot, File Upload, Signature, Text Entry, Form Field, and structural elements like Descriptive Text and Page Break.

What is the difference between a Matrix and a Side by Side question in Qualtrics?+

A Matrix question has multiple row statements rated on a single shared scale (one set of column headers). A Side by Side question has multiple row statements rated on multiple sub-questions simultaneously, with each sub-question appearing as a column group. Side by Side is more compact for multi-attribute ratings where each item needs to be evaluated on several dimensions at once.

Does Qualtrics have a native NPS question type?+

Yes. Qualtrics includes a dedicated NPS question type that pre-configures the 0-10 scale with the correct endpoint labels and integrates automatically with Qualtrics CX dashboards for Promoter/Passive/Detractor calculation. Always use the native NPS type rather than a manually configured Linear Scale for NPS programmes.
