How to Add a Likert Scale in Google Forms (4 Methods)

Arun Raj•July 24, 2026•5 min read
Convert Your Survey Free
Quick Answer

Google Forms supports Likert scales through two native question types: Linear Scale (for single items) and Multiple Choice Grid (for batteries of Likert items sharing the same scale). For converting a Likert survey from a Word or PDF document, Pirai AI maps each question to the correct type automatically via Google Apps Script.

What a Likert Scale Requires in Google Forms

A Likert scale asks respondents to rate their level of agreement with a statement, typically on a 5-point or 7-point scale from "Strongly Disagree" to "Strongly Agree." In professional survey platforms this is a single question type. In Google Forms, the right approach depends on whether you have a single Likert item or a battery of items sharing the same scale.

Four Methods for Likert Scales in Google Forms

1
Linear Scale (1-5 or 1-7)
Simplest

Best for single Likert items where a numeric scale with endpoint labels is sufficient. Quick to set up, renders cleanly on mobile.

How to set it up: Add a question. Select Linear scale from the dropdown. Set the minimum (1) and maximum (5 or 7). Add a label for the low end (e.g. "Strongly Disagree") and the high end (e.g. "Strongly Agree"). The numbers 1-5 display with the labels at each end.

Limitation: Only shows numeric labels at the endpoints. Respondents see numbers 1-5 but not verbal labels for each intermediate point. For research requiring full verbal anchoring at every scale point, use Method 2.
2
Multiple Choice with Full Labels
Full anchoring

Use when you need a verbal label for every scale point. Each answer option is a labelled response (e.g. "Strongly Disagree," "Disagree," "Neither," "Agree," "Strongly Agree"). Renders as radio buttons.

How to set it up: Add a question. Select Multiple choice. Type each scale point as a separate answer option in order from negative to positive. This gives you complete verbal anchoring for each option.

Limitation: Each Likert item needs its own Multiple Choice question. For a 10-item Likert battery, you create 10 separate questions. This is time-consuming to set up and takes more vertical space in the form compared to a grid format.
3
Multiple Choice Grid (Likert Battery)
Best for batteries

The most efficient format for a battery of Likert items sharing the same scale. Multiple statements as rows, scale points as columns. Respondents select one option per row in a grid layout.

How to set it up: Add a question. Select Multiple choice grid. Add each Likert statement as a row (e.g. "I find the product easy to use," "I would recommend this product"). Add each scale point as a column header (e.g. "Strongly Disagree" through "Strongly Agree"). Enable "Require a response in each row."

Limitation: On mobile, grids with 5+ columns require horizontal scrolling. For mobile-first surveys, consider keeping scale points to 5 maximum and using abbreviated column labels.

Formatting Tips for Likert Scales in Google Forms

For Linear Scale questions, the scale must start at 0 or 1 and end between 2 and 10. A traditional 5-point Likert scale sets minimum to 1 and maximum to 5. A 7-point scale sets minimum to 1 and maximum to 7. You cannot use a 0-10 NPS-style scale with the same question type as a Likert - for NPS, use a Linear Scale from 0 to 10 separately.

For Multiple Choice Grid, keep column header text short. Long scale labels truncate on mobile. "SD / D / N / A / SA" works better than "Strongly Disagree / Disagree / Neither Agree Nor Disagree / Agree / Strongly Agree" in a grid with 5 columns on a phone screen.

Frequently Asked Questions

Can Google Forms do a 5-point Likert scale?+

Yes. Use a Linear Scale question and set the minimum to 1 and maximum to 5. Add 'Strongly Disagree' as the label for 1 and 'Strongly Agree' as the label for 5. For full verbal anchoring at every point, use Multiple Choice with five labelled answer options instead.

What is the difference between Linear Scale and Multiple Choice Grid for Likert scales?+

Linear Scale is for a single Likert item with numeric endpoints. Multiple Choice Grid is for a battery of Likert items where multiple statements share the same scale - it displays them in a grid with statements as rows and scale points as columns. Use Grid for batteries of 3 or more Likert items to save space.

Does Google Forms support 7-point Likert scales?+

Yes. Use a Linear Scale question and set the maximum to 7. Or use Multiple Choice with seven labelled answer options. Multiple Choice Grid supports as many columns as you add, so a 7-point scale becomes 7 column headers.
