How to Create a Kahoot Quiz From a Word or PDF Document (2026)

Arun Raj•August 02, 2026•5 min read•Guide
Quick Answer

Kahoot cannot open Word documents or PDFs directly. To create a Kahoot quiz from an existing document: upload your Word or PDF file to platform.piraiai.com, select Kahoot, download the Excel spreadsheet, and import it via the Kahoot creator (three-dot menu > Import). Your questions appear in the Kahoot editor. Add images, true/false questions, and slides manually after import.

Can Kahoot Import a Word or PDF File?

No. Kahoot's import feature only accepts Excel spreadsheets (.xlsx) structured to its specific column format - not Word documents, PDFs, Google Docs, or plain text files. There is no file upload for documents in the Kahoot creator, and pasting from a document builds questions one card at a time through the manual interface.

This means the process of creating a Kahoot from an existing quiz document requires an intermediate step: converting the document to Kahoot's spreadsheet format before importing. Pirai AI automates this intermediate step.

Method 1: Build From Scratch in Kahoot Creator

Go to kahoot.com. Click Create. Choose Quiz. For each question: click the + button, type the question (max 95 characters), add up to four answer options (max 60 characters each), click the correct answer, set the time limit. Add a title and description. Save and share. Best when: creating a new quiz from scratch with under 10 questions. For larger quizzes or documents with existing questions, the card-by-card interface is significantly slower than the spreadsheet import.

Method 2: Kahoot Spreadsheet Template (Manual)

From the Kahoot creator, go to the three-dot menu > Import > Download template. Fill the spreadsheet with one question per row: question text, four answers, time limit in seconds, correct answer number (1-4). Save as .xlsx. Upload via Import. Works if your questions are already in a simple tabular format. Not efficient for document-format questions that require manual reformatting into rows.

After Import: What to Add Manually

Kahoot's spreadsheet import creates multiple choice questions only. After importing, add these manually in the creator: True/False questions (add as a Quiz question with two options), content slides (for instructions or transitions between topics), open-ended questions (available on creator plans), images on questions or answers, and background music for the game. For a 30-question quiz with 25 multiple choice and 5 true/false questions, importing the 25 MCQ via spreadsheet takes under 5 minutes, then add the 5 true/false manually - faster than building all 30 card-by-card.
