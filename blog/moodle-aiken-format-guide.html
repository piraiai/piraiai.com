Moodle AIKEN Format: Complete Guide With Examples and Error Fixes

Arun Raj•August 02, 2026•5 min read•Guide
What AIKEN Format Is

AIKEN is Moodle's simplest question import format - a plain text (.txt) file where each multiple choice question follows a strict three-part structure: the question text on one line, lettered answer options each on their own line, and an ANSWER: line identifying the correct option. The format requires precise capitalisation, spacing, and UTF-8 file encoding. Any deviation causes a failed or incorrect import.

The Exact AIKEN Syntax

Every AIKEN question follows this structure with no variations permitted:

What is the capital of France?
A. London
B. Berlin
C. Paris
D. Madrid
ANSWER: C

Which of the following is a mammal?
A. Salmon
B. Eagle
C. Dolphin
D. Gecko
ANSWER: C

Rules that must be followed exactly:

  • The question text must be on a single line - no line breaks within a question
  • Answer options must use single uppercase letters followed by a period and space: A. or A) - both are accepted but must be consistent throughout the file
  • The correct answer line must start with ANSWER: (all capitals, colon, single space) followed by the correct letter
  • Questions must be separated by a blank line
  • The file must be saved as plain text (.txt) with UTF-8 encoding

Common AIKEN Import Errors and Fixes

"No questions imported" or blank import: Almost always caused by wrong file encoding. Open the .txt file in Notepad (Windows) > File > Save As > Encoding: UTF-8. On Mac, save from TextEdit in plain text format. Word files copy-pasted into Notepad can sometimes carry ANSI encoding - always confirm UTF-8 before import.

"answer" not recognised: The ANSWER: line must be exactly ANSWER: C - all capitals, colon, one space, correct letter. Lowercase answer: C, missing space ANSWER:C, and extra space ANSWER: C all cause the import to fail or misread the correct answer.

Smart quotes breaking the import: Word and Google Docs replace straight apostrophes and quote marks with "smart" curly versions ('quoted' instead of 'quoted'). These are non-ASCII characters that break AIKEN parsing. Always paste through a plain text editor (Notepad, Notepad++) to strip smart quotes before saving as .txt.

Question text split across lines: AIKEN requires the entire question on one line. A question with a line break in it is treated as two separate items and causes parsing errors. Ensure line wraps in your source document are converted to single-line text before formatting as AIKEN.

Missing blank line between questions: AIKEN uses blank lines to separate questions. Missing the blank line between the ANSWER: of one question and the start of the next question merges the two questions into one invalid entry.

When to Use GIFT Instead of AIKEN

GIFT format is more complex than AIKEN but supports true/false, short answer, numerical, matching, and essay questions alongside multiple choice. If your quiz bank contains mixed question types, GIFT is worth learning. The GIFT format for a multiple choice question looks like:

::Question title::What is the capital of France? {
  =Paris
  ~London
  ~Berlin
  ~Madrid
}

GIFT uses = for correct answers and ~ for incorrect options. The syntax is more error-prone than AIKEN but unlocks the full Moodle question type range. Pirai AI currently generates AIKEN format; for GIFT, use a dedicated GIFT editor or export from an existing Moodle instance.

Frequently Asked Questions

What is Moodle AIKEN format?+

Moodle AIKEN format is a plain text (.txt) import format for multiple choice questions. Each question follows a three-part structure: question text on one line, lettered answer options (A. B. C. D.) on separate lines, and ANSWER: followed by the correct letter. The file must be saved with UTF-8 encoding. AIKEN only supports single-answer multiple choice - for other question types, use GIFT format.

Why does my AIKEN import fail in Moodle?+

The most common causes: (1) lowercase 'answer:' instead of 'ANSWER:'; (2) file saved in ANSI instead of UTF-8 encoding; (3) smart quotes from Word replacing straight apostrophes; (4) question text on multiple lines instead of one; (5) missing blank line between questions. Pirai AI's generated AIKEN files avoid all five of these automatically.

What is the difference between AIKEN and GIFT format in Moodle?+

AIKEN is simpler and supports only single-answer multiple choice questions. GIFT is more complex but supports multiple choice, true/false, short answer, numerical, matching, and essay questions. AIKEN is the right choice for MCQ-only quiz banks; GIFT is needed for mixed question types.

Can AIKEN format include images in Moodle questions?+

No. AIKEN format is plain text only - images cannot be included in the .txt file. After importing via AIKEN, open each question in the Moodle question editor and add images manually to the question text or answer options using the rich text editor.
