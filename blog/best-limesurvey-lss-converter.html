What Is a LimeSurvey LSS File

LSS (LimeSurvey Structure) is the XML-based file format LimeSurvey uses for survey import and export. It contains the complete survey definition: survey settings, language data, question groups, questions, answer options, and their relationships. Importing an LSS file into LimeSurvey creates the complete survey instantly without manual question entry.

LSS files have two major versions based on the LimeSurvey database schema (DB) version:

  • DB version 5 - compatible with LimeSurvey 3.x
  • DB version 6 - compatible with LimeSurvey 4.x and 5.x (current installations)

Using the wrong DB version for your LimeSurvey installation causes an import error. Pirai AI lets you choose the correct version before downloading.

Multilingual LSS Support

LimeSurvey has native multilingual support and Pirai AI preserves verbatim text from source documents in any language. For multilingual studies, upload each language version of the instrument separately and generate an LSS file per language. Import the primary language version first, then use LimeSurvey's Translation interface (Survey settings > Survey texts) to add additional languages. Participant language selection is managed automatically by LimeSurvey at the survey URL level.
