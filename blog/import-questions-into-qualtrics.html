How to Import Questions into Qualtrics: 4 Methods (2026)

Arun Raj•July 18, 2026•3 min read•Glossary
Definition

Qualtrics supports four main methods for importing questions into a survey: manual question-by-question entry, text file upload via the Auto-Number feature, copying from the Question Library, and AI-powered document conversion via Pirai AI. Each suits different source formats and question volumes.

Method 1: Manual Question Entry

The default Qualtrics workflow: click the + button to add questions one at a time, select the question type, type the question text, add answer options, and configure any settings. For surveys of 5-10 questions, this is the most direct approach. For anything longer, manual entry is slow and introduces transcription errors - particularly for surveys with many answer options or matrix items.

Best for: Short surveys built from scratch, small additions to existing surveys, single complex questions requiring detailed custom configuration.

Method 2: .TXT Auto-Number Upload

Qualtrics supports importing questions from a .txt file formatted in Qualtrics' "Auto-Number" syntax. This is Qualtrics' native bulk import option. The .txt file uses simple markup to define question types and answer options.

The basic format:

[[AdvancedFormat]]

[[Question:MC:SingleAnswer]]
[[ID:Q1]]
How satisfied are you with our service?

[[Choices]]
Very satisfied
Satisfied
Neutral
Dissatisfied
Very dissatisfied

To import: In the Survey tab, click Tools (top right) then Import Survey. Select your .txt file. Qualtrics adds the questions to the survey.

Limitation: The Auto-Number format requires precise syntax - incorrect formatting causes import errors. Matrix questions, piped text, and complex logic are difficult to express in this format. The syntax is not intuitive for researchers unfamiliar with it.

Method 3: Question Library Copy

Qualtrics' Question Library stores reusable questions and blocks that can be copied into any survey in the same Qualtrics account (or shared across accounts with appropriate permissions). If your organisation uses standardised questions (an institutional NPS item, a validated demographic block, approved satisfaction scales), saving them to the library and importing from there is the most efficient approach for recurring use.

To use: In the Survey editor, click the import icon on a block. Select "Import questions from library." Browse or search your library. Select the questions and click Import.

Best for: Standardised institutional questions, validated scales used repeatedly, shared question banks across a research team or organisation.

Method 4: Pirai AI Document Conversion

Pirai AI converts Word (.docx), PDF, and Excel (.xlsx) survey documents directly to Qualtrics QSF format for import. Upload your document, select Qualtrics as the target, and download a QSF file. Import it via Survey tab > Tools > Import Survey. Every question, answer option, matrix structure, and scale label from your source document appears in the Qualtrics editor.

This approach handles all question types that the Auto-Number format struggles with: Matrix Table questions with custom scale labels, Likert batteries, rank order questions, and constant sum questions are all converted correctly. A 60-item validated research instrument from a PDF can be in Qualtrics in minutes rather than hours.

After import, add branching logic, embedded data, quotas, and display conditions in the Qualtrics editor - these platform-specific features are configured post-import.

After Importing Into Qualtrics

After a QSF import via Method 4, your questions appear in the Survey Builder with correct types and answer options. Three things still require manual setup in Qualtrics after any import:

Display logic: Display logic conditions reference specific Question IDs (QID1, QID2, etc.) that are assigned at import time. If your source document has branching annotations, review and configure these in the Survey Builder after import using the actual QIDs. Survey Flow: Block randomisation, branch logic, and embedded data variables are configured in Survey Flow after import - these are Qualtrics-specific features that do not exist in source documents. Look and feel and distribution: Theme, progress bar, button labels, and anonymous vs. tracked link settings are survey-level settings configured separately in the Look & Feel and Distributions tabs.

For validated research instruments where exact item wording must be preserved, verify each imported field label against the source document before activating the survey. Pirai AI preserves verbatim text from the source document, but a final QA pass is good practice before fieldwork begins.

Frequently Asked Questions

Can I import questions into Qualtrics from Word?+

Yes, via Pirai AI. Upload your Word document to platform.piraiai.com, select Qualtrics as the target, and download the QSF file. Import it into Qualtrics via Survey tab > Tools > Import Survey. All questions, answer options, and matrix structures from your Word document are imported into the Qualtrics editor.

What is the Qualtrics Auto-Number import format?+

Qualtrics Auto-Number is a plain text (.txt) format that uses markup tags like [[Question:MC:SingleAnswer]] and [[Choices]] to define questions and answer options. It is Qualtrics' native bulk import format but requires precise syntax and does not support complex question types like matrix tables easily.

How do I import a validated survey instrument into Qualtrics?+

Upload the instrument document (Word or PDF) to Pirai AI, select Qualtrics as the target, and download the QSF file. Import it via Qualtrics Survey tab > Tools > Import Survey. The exact item wording and scale labels from the validated instrument are preserved in the import.

Can Pirai AI convert a REDCap data dictionary to Qualtrics?+

Yes. Export your REDCap instruments as a data dictionary CSV. Upload it to Pirai AI, select Qualtrics as the target, and download the QSF file. The REDCap field types are mapped to the closest Qualtrics question types.

How long does it take to import a 50-question survey into Qualtrics?+

Manual entry in the Qualtrics Survey Builder takes 6-8 hours for a 50-question survey with matrix questions. The TXT Auto-Number format requires similar preparation time. Using Pirai AI to generate a QSF from the source document takes under 15 minutes, including the conversion and the Qualtrics import step. Remaining configuration (display logic, Survey Flow, look and feel) adds 1-3 hours depending on complexity.

Can I import a PDF into Qualtrics directly?+

No. Qualtrics cannot read PDF files - its import only accepts QSF files and TXT/DOCX files in Auto-Number format. To import questions from a PDF into Qualtrics, upload the PDF to Pirai AI at platform.piraiai.com, select Qualtrics, download the QSF file, and import it via Survey tab > Tools > Import Survey. For scanned PDFs, enable Advanced PDF Processing for OCR text extraction.

Does Pirai AI preserve matrix questions when importing to Qualtrics?+

Yes. Matrix questions from your source document are converted to Qualtrics' Matrix Table question type, with all row statements and column scale labels preserved from the original. This is the biggest time saving compared to manual entry - a single matrix table with 8 rows takes 15-20 minutes to build manually in Qualtrics, and a document with 5 or 6 matrix blocks can add hours to programming time.
