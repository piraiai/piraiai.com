Qualtrics Question Types: Complete Guide With Examples

Arun Raj•September 1, 2026•6 min read•Guide
Qualtrics Question Types

Qualtrics offers more than 20 question types covering everything from simple multiple choice to advanced conjoint analysis and behavioural heat maps. Choosing the right question type for each survey item affects data quality, respondent experience, and how easily you can analyse results. This guide covers the question types used most commonly in research surveys, with examples and when to use each.

Multiple Choice

The most commonly used Qualtrics question type. Presents a list of options for respondents to select.

Single Answer: Radio button format - respondent selects exactly one option. Use for: categorical demographic variables, any question with mutually exclusive options.

Multiple Answer: Checkbox format - respondent selects one or more options. Use for: "Select all that apply" questions, multi-select preference questions.

Dropdown: Options appear in a dropdown menu instead of as visible radio buttons or checkboxes. Use for: long option lists (countries, institutions) where visible radio buttons would take excessive screen space.

Select Box: Standard HTML select element. Use for: basic categorical selection in simpler survey contexts.

Matrix

A grid format where multiple row items are each rated against the same set of column options. The standard format for Likert scales, attitude batteries, and frequency scales in research surveys.

Likert: Row items rated on a named scale (Strongly Agree to Strongly Disagree, Never to Always). The most common Matrix sub-type in academic research.

Bipolar: Scale with opposing labels at each end (e.g. Not at all important -- Extremely important). Use for semantic differential and bipolar scales.

Rating Scale: Numeric scale (e.g. 1-7) as column options. Use for performance ratings and numeric attribute evaluations.

Matrix of Dropdown Menus: Each cell in the grid contains a dropdown instead of radio buttons. Use for complex experimental designs.

Text Entry

Single Line: One-line text input. Use for names, short answers, numeric values, dates. Add validation (number, text length, date) under Question Options.

Multi Line (Essay Box): Multi-line text area. Use for open-ended qualitative responses, explanations, comments.

Form Field: Multiple labelled text inputs in one question. Use for address collection, contact information, structured multi-field responses.

Password Field: Masked text input. Use for PIN or code entry.

Slider

A visual drag-and-drop scale. Use for continuous rating scales where respondents should not be anchored to discrete numeric choices.

Single Slider: One item rated on a continuous scale with start and end labels.

Star Rating: Star icon visual rating (1-5 stars). Use for satisfaction and experience questions where visual metaphor matches the construct.

Other Research-Relevant Question Types

Rank Order: Respondents drag items into ranked order. Use for priority ordering, preference ranking, importance hierarchy questions.

Net Promoter Score (NPS): 0-10 scale with "How likely are you to recommend...?" wording built in. Use for standard NPS measurement.

Constant Sum: Respondents allocate points (adding to 100) across options. Use for budget allocation, time distribution, weight attribution.

Text/Graphic: Display-only block - no data collection. Use for instructions, consent text, section introductions, images, and videos between question groups.

Timing: Records how long a respondent spends on a page. Use for attention checks in experimental studies.

Frequently Asked Questions

What is the difference between Multiple Choice Single Answer and Multiple Answer in Qualtrics?+

Single Answer presents radio buttons - respondent selects exactly one option. Multiple Answer presents checkboxes - respondent selects one or more options. Use Single Answer for questions with mutually exclusive options (e.g. What is your highest education level?). Use Multiple Answer for select-all-that-apply questions (e.g. Which platforms do you use?).

What is a Matrix question in Qualtrics?+

A Matrix question presents multiple row items rated against the same set of column options in a grid. It is the standard format for Likert scales - attitude, agreement, frequency, and satisfaction batteries where several items are rated on the same scale. Sub-types include Likert, Bipolar, and Rating Scale.

When should I use a Slider vs Multiple Choice in Qualtrics?+

Use Slider for continuous rating scales where the precision of a drag position adds value - visual analog scales (VAS) in clinical research, effort and emotion measures in experimental studies. Use Multiple Choice when respondents should select from defined discrete options and anchoring to labeled choices is appropriate.
