What Is a REDCap Data Dictionary

A REDCap Data Dictionary is an 18-column CSV file that defines every field in a REDCap project - its name, type, label, answer choices, validation rules, and branching logic. It is the only way to bulk-create fields in REDCap from an external source. Building it manually requires understanding every column's requirements and entering each field's properties individually. Pirai AI generates the complete Data Dictionary from your source document automatically.

Key columns Pirai AI populates:

  • Variable/Field Name: Lowercase, underscores, auto-generated from field label
  • Form Name: Survey or form assignment
  • Field Type: text, radio, checkbox, dropdown, slider, notes, calc - detected from question structure
  • Field Label: Verbatim question text from source document
  • Choices: Pipe-delimited format - 1, Option A | 2, Option B | 3, Option C
  • Field Note: Additional context from source document
