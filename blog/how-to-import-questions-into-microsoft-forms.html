How to Import Questions Into Microsoft Forms (2026 Guide)

Arun Raj•August 04, 2026•5 min read•Guide
Quick Answer

Microsoft Forms has a built-in Quick Import that accepts Word (.docx) and PDF files. Access it from the form editor: three-dot menu (...) > Import questions. Quick Import supports Multiple Choice and Open Text question types. Likert scales, matrix grids, NPS, Ranking, Rating, and Date questions are flagged as unsupported and must be added manually. Pirai AI pre-processes your document so matrix and Likert questions are expanded into Choice questions that Quick Import handles without flagging.

How Microsoft Forms Quick Import Works

Quick Import is Microsoft Forms' native document import feature. It reads a Word or PDF file and creates questions in the form editor automatically. Not all question types are supported - the import was designed primarily for simple quizzes and surveys with multiple choice and open text questions.

Access Quick Import from any form: click the three-dot menu (...) in the top right of the form editor, select Import questions, upload your file, choose Form or Quiz, and click Next. After processing, click Start Review to see imported questions and any flagged items.

Three Ways to Import Questions Into Microsoft Forms

Method 1: Direct Quick Import (Simpler Surveys)

Upload your Word or PDF file directly via three-dot menu > Import questions. Works cleanly for surveys that are mostly Multiple Choice and Open Text. For best results before uploading: put questions vertically with answer options on separate numbered lines (1. 2. 3.), remove tables and images, keep file size under 10MB. After import, work through the Start Review screen to resolve any flagged items.

Method 2: Pirai AI Pre-Processing + Quick Import (Complex Surveys)

For surveys with Likert scales, matrix grids, or other non-supported types, Pirai AI pre-processes the document before Quick Import. Matrix and Likert questions are expanded into individual Choice questions - which Quick Import handles cleanly. NPS, Ranking, Rating, File Upload, and Date questions still need to be added manually after import, but the bulk of the question structure imports without flagging.

Method 3: Manual Entry

Click Add new in the form editor. Select the question type. Enter the question text and answer options. Best for small additions (under 10 questions) or for the native Likert, NPS, Ranking, and Rating types that Quick Import cannot create - these must always be added manually regardless of which import method you use.

Resolving Flags in Start Review

After Quick Import, Start Review shows three types of flags: Missing content (items skipped entirely), Uncertain conversion (imported but question type may be wrong), and Unsupported question type (type Quick Import cannot create). For each flag: click it to see what was detected, either correct the question type in the review panel or dismiss and add the question manually, then mark it Resolved. Click Done when all flags are resolved.

Frequently Asked Questions

How do I import questions into Microsoft Forms from a Word document?+

Go to forms.office.com, open or create a form, click the three-dot menu (...) in the top right, and select Import questions. Upload your Word (.docx) file, choose Form or Quiz, click Next, then Start Review. Quick Import supports Multiple Choice and Open Text. Likert, matrix, NPS, Ranking, Rating, and Date questions are flagged as unsupported and must be added manually.

What question types can I import into Microsoft Forms?+

Microsoft Forms Quick Import supports Multiple Choice (single and multi-select) and Open Text (short and long answer). Likert scales, matrix grids, NPS, Ranking, Rating (stars), File Upload, and Date questions are not supported by Quick Import and must be added manually in the form editor after import.

Why are my questions flagged after Microsoft Forms Quick Import?+

Quick Import flags items it cannot convert: Unsupported question type (Likert, NPS, Ranking, Rating), Missing content (skipped items), and Uncertain conversion (imported but possibly wrong type). Click each flag in Start Review to see what was detected and either correct it or add the question manually.

Can I import a PDF into Microsoft Forms?+

Yes. Microsoft Forms Quick Import accepts PDF files. Go to the form editor, three-dot menu (...) > Import questions, upload the PDF, choose Form or Quiz, and click Next. The same question type limitations apply as for Word files - Multiple Choice and Open Text import cleanly; others are flagged.

How do I import Likert scale questions into Microsoft Forms?+

Likert scale questions cannot be imported by Quick Import - they are flagged as Unsupported question type. Two options: use Pirai AI to pre-process your document (which expands Likert rows into individual Choice questions that Quick Import handles), or add Likert questions manually in the form editor via Add new > More question types > Likert after importing the other questions.
