LimeSurvey Question Types: Complete Guide With Examples

Arun Raj•August 28, 2026•6 min read•Guide
LimeSurvey Question Types

LimeSurvey supports more than 20 question types covering everything from simple single-answer multiple choice to complex ranking, matrix, and numerical grid formats. Choosing the right question type for each survey item is important for data quality and the respondent experience. This guide covers the most-used question types in research surveys, with examples of when to use each.

Single Answer Question Types

List (Radio) - The most common question type. Respondent selects one option from a list presented as radio buttons. Use for: demographic questions (gender, age group, education), categorical variables, any question with a defined set of mutually exclusive options. Appears in the LSS as type L.

List (Dropdown) - Same as List (Radio) but options appear in a dropdown menu. Use for: long lists (countries, languages, institutions) where radio buttons would take too much screen space. Appears in the LSS as type ! (exclamation mark).

List With Comment - List (Radio) with an additional open text field for respondents who select "Other". Use for: questions where the predefined options may not cover all responses. Appears in the LSS as type O.

5 Point Choice / Dual Scale - Specialised Likert-style single answer. Use for simple 5-point scales embedded directly in the question rather than an Array.

Multiple Answer Question Types

Multiple Choice - Respondent selects one or more options from a list (checkboxes). Use for: "Select all that apply" questions, multi-select preference questions. Appears in the LSS as type M.

Multiple Choice With Comments - Multiple Choice with an optional comment field per option. Use for: situations where respondents may need to explain why they selected certain options. Appears as type P.

Array (Matrix) Question Types

Array (Likert) - A matrix grid where row items are rated against a set of column scale options (Strongly Agree to Strongly Disagree, Never to Always, etc.). The most common format for validated psychometric scales. Use for: attitude scales, opinion batteries, frequency scales. Appears in the LSS as type F.

Array (Numbers) - Matrix grid where rows are rated on a numerical scale. Use for: satisfaction ratings 1-10, importance ratings, performance assessments. Appears as type ;

Array (Dual Scale) - Matrix with two parallel response scales per row item. Use for: importance-performance analysis, dual attribute ratings. Appears as type 1.

Array (Text) - Matrix grid where each cell accepts free text. Use for: detailed evaluation grids where numeric or categorical options are insufficient. Appears as type H.

Text Input Question Types

Short Free Text - Single-line text input. Use for: names, short responses, numeric values without validation. Appears as type S.

Long Free Text - Multi-line text area. Use for: open-ended qualitative responses, detailed explanations, comments fields. Appears as type T.

Huge Free Text - Large multi-line text area. Use for: essay-length responses, detailed narrative data. Appears as type U.

Numerical Input - Number-only input with optional min/max validation. Use for: ages, counts, monetary values, numeric scores. Appears as type N.

Date/Time - Date or datetime picker. Use for: event dates, appointment times, date-of-birth fields. Appears as type D.

Display and Structure Types

Text Display - Display-only text or HTML. No data collected. Use for: section introductions, instructions, consent text, separator blocks between question groups. Appears as type X.

Ranking - Respondents drag and rank items in order of preference. Use for: priority ordering, preference ranking. Appears as type R.

Frequently Asked Questions

What is the most common LimeSurvey question type for research surveys?+

Array (Likert) is the most common for validated psychometric research scales - it creates a matrix grid where respondents rate row items against a set of scale column options (Strongly Agree to Strongly Disagree, Never to Always). List (Radio) is the most common for single-answer multiple choice questions. Both are auto-detected by Pirai AI from document structure.

What is the difference between List (Radio) and Array in LimeSurvey?+

List (Radio) presents one question with a set of single-answer radio button options - respondent picks one. Array (Likert) presents multiple row items in a matrix, all rated against the same set of scale column options. Array is used for Likert scales where the same response options apply to multiple questions shown in a grid.

How do I create an Array (Likert) question in LimeSurvey?+

In LimeSurvey's Survey Structure editor, add a question and select Array (Likert) as the type. Add row items (the individual sub-questions) and column options (the scale labels: Strongly Agree, Agree, etc.). In Pirai AI, Word tables with row items and column scale labels are automatically detected as Array questions and exported correctly in the LSS file.
