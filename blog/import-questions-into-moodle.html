How to Import Questions Into Moodle From Word, PDF, or Excel

Arun Raj•August 02, 2026•5 min read•Guide
Quick Answer

Moodle has no native Word or PDF import. Questions must be imported via text-based formats - primarily AIKEN (.txt, for multiple choice only) or GIFT (.txt, for multiple question types). To import questions from a Word or PDF document: upload to platform.piraiai.com, select Moodle, download the AIKEN .txt file, and import via Question Bank > Import > Aiken Format. Questions appear in your question bank ready for use in a quiz.

Why Moodle Has No Direct Document Import

Moodle's question bank stores questions in a structured database format with fields for question type, question text, answer options, correct answers, feedback, and grading settings. A Word document has no standard structure Moodle can parse to identify these fields. Every LMS including Moodle, Canvas, Blackboard, and Brightspace requires questions to be formatted in a specific text-based exchange format before import.

Moodle supports over a dozen import formats, but two are practical for document-based conversion: AIKEN (the simplest, for multiple choice only) and GIFT (more powerful, supports most Moodle question types). Pirai AI generates AIKEN format automatically from your source document.

AIKEN vs GIFT: Which Format to Use

FormatSupportsBest For
AIKENMultiple Choice (single correct answer) onlyQuick import of MCQ-only quiz banks. Simplest format - easiest to troubleshoot.
GIFTMultiple Choice, True/False, Short Answer, Numerical, Matching, EssayMixed question type quizzes. More complex syntax but supports the full Moodle question range.
Moodle XMLAll Moodle question types including images and feedbackFull-featured import including question feedback, tags, and images. Most complex format.

Three Ways to Import Questions Into Moodle

Method 1: Manual Entry in Moodle Question Bank

In your Moodle course, go to the gear menu > More > Question bank > Add > a new question. Select the question type (Multiple Choice, True/False, Short Answer, etc.), enter the question text, add answer options, set correct answers and feedback, save. Repeat for every question. Time-consuming for large question banks. No transcription risk if you copy-paste directly from the document. Best for small additions to an existing question bank.

Method 2: Format as AIKEN .txt and Import

Open a text editor (Notepad on Windows, TextEdit on Mac in plain text mode). Format each question to AIKEN syntax - question on one line, answers labelled A. through D. on separate lines, ANSWER: on the final line. Save as .txt with UTF-8 encoding. In Moodle: Question bank > Import > Aiken format > upload the file. Practical for quiz banks that are already simple MCQ lists. Not practical for mixed question types or documents with complex formatting.

What Happens to Non-MCQ Questions

AIKEN only supports multiple choice questions with a single correct answer. When Pirai AI converts a document containing mixed question types:

  • True/False questions are converted to two-option Multiple Choice questions (A. True / B. False / ANSWER: A)
  • Multiple answer questions (select all that apply) are flagged in the conversion report - AIKEN cannot represent these and they must be added manually as Multiple Choice (Multiple Answers) in the Moodle question editor
  • Short answer and essay questions are skipped in the AIKEN output and listed in the conversion report - add these manually in Moodle's Question bank
  • Matrix questions are expanded to individual MCQ questions per row

Frequently Asked Questions

Can Moodle import a Word document directly?+

No. Moodle cannot open or import Word documents, PDFs, or Excel files directly into the question bank. Questions must be imported via text-based formats: AIKEN (.txt) for multiple choice, GIFT (.txt) for mixed question types, or Moodle XML. To import from a Word document, convert it to AIKEN .txt using Pirai AI, then import via Question bank > Import > Aiken format.

How do I import quiz questions from a Word document into Moodle?+

Upload the Word document to Pirai AI at platform.piraiai.com, select Moodle, and download the AIKEN .txt file. In Moodle, go to the course gear menu > More > Question bank > Import. Select Aiken format. Upload the .txt file and click Import. Questions appear in your question bank.

What is the difference between AIKEN and GIFT format in Moodle?+

AIKEN is a simple plain text format for importing multiple choice questions only - each question on one line, lettered answers, and ANSWER: at the end. GIFT is a more complex format that supports multiple choice, true/false, short answer, numerical, matching, and essay questions. Pirai AI generates AIKEN format; for GIFT, use the manual approach or Moodle's own XML export from another Moodle instance.

Why does my AIKEN import fail in Moodle?+

Common causes: (1) lowercase 'answer:' instead of 'ANSWER:' - must be all capitals; (2) file saved in ANSI encoding instead of UTF-8; (3) smart quotes from Word ('answer') instead of straight quotes; (4) question text spanning multiple lines instead of being on one line; (5) extra spaces before answer letters. Pirai AI handles all of these correctly in the generated AIKEN file.

Can I import true/false questions into Moodle using AIKEN format?+

AIKEN does not have a native true/false question type. True/False questions can be converted to two-option Multiple Choice format: A. True / B. False / ANSWER: A. Pirai AI converts true/false questions from source documents to this MCQ format for AIKEN import. You can then change the question type to True/False in the Moodle question editor after import.
