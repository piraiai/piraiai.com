Qualtrics Advanced Format: Complete Guide With Examples (2026)

Arun Raj•August 02, 2026•5 min read•Guide
What Advanced Format Is

Qualtrics Advanced Format is a specific .docx or .txt document structure that Qualtrics' import tool can read as a survey. It uses Word heading styles and question type codes to define blocks, questions, and answer options. It is not a general document import - it is a template format that must be built from scratch. Most researchers find creating a QSF file via Pirai AI faster than preparing an Advanced Format document.

What Advanced Format Actually Is

When Qualtrics says you can "import a Word document," what they mean is: you can import a .docx file that has been specifically structured using Qualtrics' Advanced Format rules. This is different from uploading a survey you have already written in Word. The Advanced Format has its own heading structure, question type codes, and syntax rules that must be followed precisely - any deviation causes a failed import.

The result is that researchers who attempt to import their existing survey document into Qualtrics are typically disappointed. The document they have needs to be rebuilt from scratch following Advanced Format rules - which takes nearly as long as manual entry in the Survey Builder.

Advanced Format Document Structure

An Advanced Format .docx uses Word heading styles and specific codes to define the survey structure:

  • Heading 1 - Block name (e.g. "Block 1: Demographics")
  • Heading 2 - Question text (each question is a Heading 2 paragraph)
  • Normal/Body text - Answer options (one per line)
  • Question type codes - Placed before the question text: [[MC]], [[TE]], [[Matrix]], [[CB]], [[RO]], [[CS]]

Advanced Format Limitations

Matrix scale headers must be separated by "---" (three hyphens). Getting the separator syntax wrong is the most common cause of failed matrix imports. Display logic cannot be specified in Advanced Format - it must be configured manually in the Survey Builder after import. Embedded data and Survey Flow elements are not included. Question validation rules must be added post-import. File must be .docx or .txt - PDFs and Excel files cannot use Advanced Format.

Frequently Asked Questions

What is Qualtrics Advanced Format?+

Qualtrics Advanced Format is a specific .docx or .txt document structure that Qualtrics' import tool can read as a survey. It uses Word Heading 1 for block names, Heading 2 for question text, body text for answer options, and question type codes like [[MC]], [[TE]], and [[Matrix]]. It must be built from scratch - it cannot be created by reformatting an existing survey document.

What are the Qualtrics Advanced Format question type codes?+

The main codes are: [[MC]] for Multiple Choice (single select), [[MC:MultipleAnswer]] for multi-select, [[TE]] for short text entry, [[TE:Essay]] for paragraph text, [[Matrix]] for Matrix Table/Likert grid, [[CB]] for Checkboxes, [[RO]] for Rank Order, [[CS]] for Constant Sum, and [[Slider]] for Slider questions.

Why does my Qualtrics Word import fail?+

The most common causes are: (1) uploading a standard Word document instead of one built in Advanced Format; (2) incorrect heading styles - question text must use Heading 2, not bold body text; (3) matrix scale headers not separated by '---'; (4) missing or incorrectly placed question type codes. For complex surveys, use Pirai AI to generate a QSF file instead of Advanced Format.

Is Advanced Format faster than building manually in Qualtrics?+

For surveys under 20 simple questions, Advanced Format can be slightly faster than manual entry. For surveys with matrix questions, complex blocks, or display logic, building the Advanced Format document takes nearly as long as manual entry - and introduces format error risk. QSF files generated by Pirai AI are faster for any survey over 15 questions.
