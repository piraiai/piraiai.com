How to Convert a PDF to a Kahoot Quiz (Step-by-Step, 2026)

Arun Raj•July 18, 2026•3 min read•Glossary
Definition

Converting a PDF to a Kahoot quiz requires producing an Excel spreadsheet in Kahoot's import format - Kahoot cannot read PDF files directly. The spreadsheet must have questions, up to four answer options, a correct answer flag, and a time limit per row, with question text under 95 characters and answer text under 60 characters per option.

Why PDFs Won't Import Directly into Kahoot

Kahoot has no PDF import function. Its built-in bulk import accepts only one format: an Excel spreadsheet (.xlsx) structured to Kahoot's specific column template. A PDF full of multiple choice questions must be converted to that spreadsheet before Kahoot can read it. There is no workaround - even if you copy and paste PDF text into Kahoot's editor, you must enter each question individually.

What Kahoot's Import Format Requires

Before choosing a conversion method, understand what Kahoot's spreadsheet import actually needs:

  • Question text: Maximum 95 characters including spaces
  • Answer options: Maximum 60 characters per option including spaces
  • Answer columns: Up to 4 options (Answer 1, Answer 2, Answer 3, Answer 4)
  • Correct answer: A column indicating which answer number is correct (1-4)
  • Time limit: Seconds per question (5-120)
  • File size: Maximum 1MB per spreadsheet upload
  • Question count: Up to 100 questions per quiz

The 95-character question limit and 60-character answer limit are the most common cause of import failures. A typical exam question like "Which amendment to the US Constitution abolished slavery throughout the United States?" is 82 characters - fine. But wordy questions from textbook PDFs frequently exceed 95 characters and must be shortened before Kahoot will accept them.

Method 1: Manual Spreadsheet (Free, Slow)

Download Kahoot's official import template from their support documentation. Open it in Excel. For each question in your PDF, type the question text into column A (checking character count), type each answer option into columns B-E, enter the time limit, and mark the correct answer column. Repeat for every question.

For a 30-question PDF quiz, this takes 45-60 minutes. Character limit checking for every question adds another 10-15 minutes. Import errors from missed limit violations send you back to the spreadsheet to edit and re-upload.

Best for: Small quizzes (under 10 questions) where you want full manual control. Not recommended for anything larger.

How to Import the Spreadsheet into Kahoot

Once you have the formatted .xlsx file:

  1. Log into your Kahoot account at kahoot.com
  2. Click Create in the top navigation
  3. Select Quiz as the game type
  4. Click Blank Canvas (not a template)
  5. In the quiz editor, click Import spreadsheet in the bottom right corner
  6. Drag and drop or click to upload your .xlsx file
  7. Click Import and then Continue
  8. Add images, adjust timers, and save your quiz

Troubleshooting Common Kahoot Import Errors

"Question text exceeds character limit." A question is over 95 characters. Shorten it. With Pirai AI, this is flagged before download so you fix it in the editor rather than after a failed import.

"Answer text exceeds character limit." An answer option is over 60 characters. Shorten the answer text. Common with answer options that are full sentences rather than short phrases.

"No correct answer specified." The correct answer column is empty for one or more questions. Pirai AI maps correct answers from your PDF's answer key if one is included. If your PDF has no answer key, you add correct answers in the editor or in the spreadsheet before uploading.

"File size exceeds 1MB." For quizzes over 100 questions or with many high-resolution images embedded, the file may exceed 1MB. Split into two separate spreadsheets and import as two quizzes.

Frequently Asked Questions

Can Kahoot import a PDF directly?+

No. Kahoot only imports quiz questions from an Excel spreadsheet (.xlsx) formatted to Kahoot's template. PDFs must be converted to that spreadsheet format first. Pirai AI converts your PDF to the Kahoot spreadsheet automatically, including checking question and answer character limits.

Kahoot questions are limited to 95 characters including spaces. Answer options are limited to 60 characters each. These are hard limits enforced at import. Pirai AI checks and flags questions that exceed these limits before you download the spreadsheet.

Can I convert a scanned PDF quiz to Kahoot?+

Yes. Upload the scanned PDF to Pirai AI and enable Advanced PDF Processing for OCR text extraction. The scanned questions are extracted and formatted into the Kahoot import spreadsheet. Review the output for OCR accuracy before importing into Kahoot.

How many questions can I import into Kahoot from a spreadsheet?+
