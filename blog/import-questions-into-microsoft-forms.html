How to Import Questions Into Microsoft Forms From Word, PDF, or Excel

Arun Raj•August 02, 2026•5 min read•Guide
Quick Answer

Microsoft Forms has a native Quick Import that accepts Word and PDF files directly. However, Quick Import only supports Multiple Choice and Open Text question types - Likert scales, matrix grids, rating questions, NPS, and ranking questions are flagged as "Unsupported question type" and must be added manually. Pirai AI pre-processes your document so that complex question types are expanded into formats Quick Import can handle, and also outputs a Pirai AI-formatted file that imports more cleanly than a raw Word document.

Three Ways to Import Questions Into Microsoft Forms

Method 1: Quick Import From Word or PDF

Microsoft Forms has a built-in Quick Import accessible from forms.office.com. From a new or existing form, click the ellipsis (...) in the top right corner and select Import questions, or click the Quick Import button if it appears in your tenant. Select a Word (.docx) or PDF file. Choose whether to create a Form or a Quiz. Click Start Review.

What Quick Import supports: Multiple Choice (single and multi-select), Open Text (short and long answer), Titles and section headings. What Quick Import does not support: Likert scale grids, matrix/rating grids, NPS questions, Ranking questions, Rating (star) questions, File Upload, Date. These appear as "Unsupported question type" flags in the Start Review screen and must be rebuilt manually.

Quick Import also requires specific document formatting: questions must be listed vertically, answer options must be on separate lines with letter or number prefixes (a., b., 1., 2.), and complex tables or figures should be removed before import. Documents not following this structure import as plain text with incorrect or missing question types.

Method 2: Duplicate an Existing Microsoft Form

If your questions are already in a Microsoft Form in your tenant, duplicate the form via the three-dot menu > Duplicate. This copies all questions and settings. Share access to a template form within your organisation to allow teams to duplicate and customise without rebuilding from scratch.

Best when: your questions already exist in a Microsoft Form. Cannot copy from Word, PDF, or Excel.

Method 3: Pirai AI Pre-Processing (For Complex Surveys)

Pirai AI reads your Word, PDF, or Excel document and generates a Microsoft Forms-optimised output file. Matrix questions are expanded into individual Choice questions (since Quick Import cannot handle grids). Likert scales are converted to individual Choice questions with the same scale options. The output file is structured precisely to Quick Import formatting requirements.

After Quick Import: Handling Flagged Items

After uploading a file and clicking Start Review, Microsoft Forms shows three types of flags: Missing content (content skipped entirely during import - usually complex formatting), Uncertain conversion (content imported but question type may be wrong), Unsupported question type (types Quick Import cannot create). For each flagged item, click the flag, review the suggested content, correct the question type or text, and click Resolved. After resolving all flags, click Done to finalise the import.

For surveys with many Likert or matrix questions, expect 20-30 minutes of post-import review to manually add the non-importable question types. Using Pirai AI to expand these into Choice questions before import reduces flagged items significantly and cuts review time.

Frequently Asked Questions

Does Microsoft Forms have a built-in import from Word?+

Yes. Microsoft Forms' Quick Import accepts Word (.docx) and PDF files. Access it via the three-dot menu (ellipsis) in the top right of the form editor and select Import questions. However, Quick Import only supports Multiple Choice and Open Text question types - Likert scales, matrix grids, NPS, and Ranking questions are flagged as unsupported and must be added manually.

Why are my questions flagged after Microsoft Forms Quick Import?+

Microsoft Forms Quick Import flags three types of issues: Missing content (skipped), Uncertain conversion (imported but potentially wrong type), and Unsupported question type (types the import cannot create: Likert, matrix, NPS, Ranking, Rating). Click each flagged item in the Start Review screen to see what was flagged, correct or manually recreate the question, and mark it Resolved.

Can I import a Likert scale into Microsoft Forms?+

Not via Quick Import - Likert questions are flagged as Unsupported and must be added manually as the Likert question type in the MS Forms editor after import. Pirai AI pre-processes documents to expand Likert batteries into individual Choice questions which Quick Import handles cleanly, reducing post-import manual work.

How do I import questions from Excel into Microsoft Forms?+

Microsoft Forms Quick Import does not accept Excel files directly. To import from Excel: upload the Excel file to Pirai AI, select Microsoft Forms, download the output file, and use Quick Import to import it. Alternatively, copy question text from Excel and use Quick Import with a structured Word document.

What document format works best for Microsoft Forms Quick Import?+

Structure your Word document vertically with questions and answers clearly separated. Use numbered or lettered answer options (1. 2. or a. b.) on separate lines below each question. Remove tables, images, and complex formatting before import. The cleaner and simpler the document structure, the fewer flagged items appear in Start Review.
