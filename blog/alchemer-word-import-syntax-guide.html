Alchemer Word Import Syntax: Complete Guide to () [] ::NewPage::

Arun Raj•August 13, 2026•5 min read•Guide
Alchemer's Word Import Format

Alchemer's Import from Word feature reads a specific text format - not plain paragraph text. Unless your text contains the right syntax markers in the right positions, Alchemer either builds nothing or creates a single text block. This guide covers every syntax rule. For most users, the practical answer is Pirai AI - upload any document, Pirai AI generates the correct syntax automatically. But understanding the format helps you verify output and troubleshoot edge cases.

How the Alchemer Importer Works

The Import from Word feature is found under Create Survey > Import from Word. It is paste-based - you copy the formatted text and paste it into the import field, then click Start Building. Alchemer reads the pasted text line by line, identifies syntax markers, and creates a question for each block it recognises. There is no file upload in this feature - it is always copy-paste.

Radio Button Questions - Single Answer

Radio buttons use ( ) before each answer option (open parenthesis, space, close parenthesis):

What is your primary industry?
( ) Technology
( ) Healthcare
( ) Financial services
( ) Retail
( ) Other

The question text appears on its own line. Each answer option appears on a new line preceded by ( ). No numbering required - Alchemer assigns numbering automatically.

Checkbox Questions - Multi-Select

Checkboxes use [ ] before each answer option (open bracket, space, close bracket):

Which of the following do you use? (Select all that apply)
[ ] Email surveys
[ ] Online survey platforms
[ ] Phone interviews
[ ] In-person interviews
[ ] Focus groups

Open Text Fields

Open text (essay) questions use a line of underscores after the question text:

What is the biggest challenge your team faces with survey programming?
____

Any number of underscore characters on a line signals an open text field. Alchemer creates an essay text box for the question.

Page Breaks

::NewPage:: on its own line creates a page break, moving subsequent questions to a new survey page:

( ) Strongly agree
( ) Agree
( ) Disagree
( ) Strongly disagree

::NewPage::

Rating Scale Questions

Rating scale questions use radio button syntax with scale endpoints as the answer options:

How likely are you to recommend us to a colleague? (1 = Not at all likely, 10 = Extremely likely)

What the Word Import Does Not Handle

Alchemer's Import from Word creates question structure and answer options. The following must be configured in the Survey Builder after import:

  • Skip logic and conditional branching (Logic tab)
  • Required field settings
  • Question validation rules (email, number range, character limits)
  • Quotas and response caps
  • Survey theme and branding
  • Answer piping and text substitution

Frequently Asked Questions

What syntax does Alchemer's Import from Word use?+

Alchemer Word Import syntax uses () for radio buttons (single-answer), [] for checkboxes (multi-select), ::NewPage:: on its own line for page breaks, and a line of underscores for open text fields. Question text appears on its own line above the answer options. Pirai AI generates all syntax automatically from any source document.

Is Alchemer Word Import a file upload or paste?+

Paste-based only. The Import from Word feature in Alchemer reads pasted text - there is no file upload option. You copy the formatted text from the Pirai AI .txt output and paste it directly into the Alchemer import field under Create Survey > Import from Word.

What does ::NewPage:: do in Alchemer?+

::NewPage:: on its own line in the import text creates a page break in the Alchemer survey. All questions after the ::NewPage:: marker are placed on a new survey page. Use it to separate survey sections and control page-by-page navigation.

Why does my Alchemer import not create any questions?+

The most common cause is missing syntax markers. If you paste plain text without () or [] before answer options, Alchemer cannot identify question structure. Ensure every answer option for a radio question is preceded by ( ) and every multi-select option by [ ]. Use Pirai AI to generate the correct syntax automatically.
