How to Create a Qualtrics Survey From a Word or PDF Document (2026)

Arun Raj•August 02, 2026•5 min read•Guide
Quick Answer

Qualtrics cannot open a standard Word document or PDF directly. To create a Qualtrics survey from an existing document, use Pirai AI: upload your Word, PDF, or Excel file at platform.piraiai.com, select Qualtrics, download the QSF file, and import it via Survey tab > Tools > Import/Export > Import Survey. A 50-question document becomes a complete Qualtrics survey in under 15 minutes.

What Qualtrics Can and Cannot Accept

Qualtrics accepts exactly two file types for survey import: QSF files (Qualtrics' native format) and .docx/.txt files structured in Qualtrics' Advanced Format. Standard Word documents, PDFs, Excel files, and CSVs cannot be imported directly - attempting to upload any of these will fail at the import step.

This surprises many researchers and survey programmers who assume that "importing a Word document" means uploading their existing survey document. The Qualtrics Word import requires a specifically structured new document - not the document you already have.

Method 1: Build From Scratch in Qualtrics

Log into Qualtrics, create a new project (Survey from scratch), and add questions one by one in the Survey Builder. For each question: click +, select the question type (Multiple Choice, Matrix Table, Text Entry, etc.), type or paste the question text, and add each answer option.

Time estimate: 3-5 minutes per simple question. 15-20 minutes per Matrix Table question. A 40-question validated instrument with 4 matrix blocks takes approximately 4-6 hours. A 60-question clinical assessment with complex branching logic: most of a work day.

Best when: Building a new survey with no existing document, or when the survey has fewer than 10 simple questions.

Method 2: Qualtrics Advanced Format (.docx/.txt)

Qualtrics' native document import reads a .docx or .txt file structured with specific formatting rules. Heading 1 = block name, Heading 2 = question text, bulleted lists = answer options. Question type codes [[MC]], [[TE]], [[Matrix]] specify the type. The file must be created fresh in this structure - you cannot convert an existing document into Advanced Format without essentially rebuilding it from scratch.

When it makes sense: If you have a survey that is already structured very simply (one question per paragraph, consistent formatting) and you need a quick route into Qualtrics without the Pirai AI step. When it fails: Matrix questions have limited Advanced Format support. Complex surveys with multiple blocks require careful structure management. Any error in the format structure causes a failed import.

Pirai AI reads your existing document in any format and generates a valid Qualtrics QSF file. No Advanced Format knowledge required. No template to follow. Upload as-is.

Importing the QSF Into Qualtrics

  1. In Qualtrics, go to the Survey tab of your project (or create a new blank project)
  2. Click Tools in the top toolbar
  3. Select Import/Export > Import Survey
  4. Click Choose File, select the .qsf file from Pirai AI
  5. Click Import
  6. All questions appear in the Survey Builder with correct question types

What to Configure After Import

Display logic: Pirai AI preserves display logic annotations from source documents where present, but Qualtrics display logic references specific Question IDs (QIDs) assigned at import time. Review and configure display logic conditions in the Survey Builder after import.

Survey Flow: Block randomisation, branch logic, and embedded data are configured in Survey Flow after import. Look and feel: Theme, progress bar, and button labels are survey-level settings configured separately. Distribution: Anonymous links, email distribution, and panel integration are set up in the Distributions tab after the survey is built.
