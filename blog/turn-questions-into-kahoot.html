How to Turn Questions Into a Kahoot Quiz (From Any Document)

Arun Raj•August 02, 2026•5 min read•Guide
Quick Answer

Kahoot's native import accepts an Excel spreadsheet (.xlsx) structured to its specific column format. You cannot paste questions directly into Kahoot or upload a Word document. To turn questions from a document into a Kahoot quiz: upload your Word, PDF, or Excel file to platform.piraiai.com, select Kahoot, download the formatted spreadsheet, and import it via the Kahoot creator (three-dot menu > Import). Your quiz is built automatically.

How Kahoot Import Actually Works

Kahoot has no Word or PDF import. Its import reads an Excel spreadsheet structured to Kahoot's exact column format - different from any spreadsheet you would write yourself. The spreadsheet has specific columns for question text, four answer options, time limit, and the correct answer letter. Every row is one question. The column headers must match Kahoot's template exactly, or the import fails.

This means turning questions from a document into Kahoot involves two steps: converting the document into Kahoot's spreadsheet format, then importing the spreadsheet. Pirai AI handles the first step automatically.

The Kahoot Import Spreadsheet Format

ColumnWhat Goes Here
QuestionQuestion text. Maximum 95 characters. Longer questions are truncated on Kahoot's game screen.
Answer 1First answer option. Maximum 60 characters.
Answer 2Second answer option. Maximum 60 characters.
Answer 3Third answer option (optional but recommended for 4-option MCQ).
Answer 4Fourth answer option (optional).
Time Limit (sec)Seconds per question. Kahoot supports: 5, 10, 20, 30, 60, 90, 120, 240. Default: 20.
Correct AnswerThe number of the correct answer column: 1, 2, 3, or 4.

Three Ways to Turn Questions Into Kahoot

Method 1: Type Questions Directly in Kahoot Creator (Small Quizzes)

Go to kahoot.com, click Create, choose Quiz. Add each question using the + button. Type the question text, add up to four answer options, select the correct answer, set the time limit. Best for quizzes with fewer than 10 questions. For anything larger, the card-by-card interface becomes slow - every question requires multiple clicks across the question card, answer fields, and correct answer selector.

Method 2: Fill In Kahoot's Spreadsheet Template (Manual)

Download Kahoot's import template from the creator (three-dot menu > Import > Download template). Open in Excel. Fill in one row per question - question text, four answers, time limit, correct answer number. Save as .xlsx. Upload via the same Import dialog. Works well if your questions are already in a simple list format without complex formatting. Time-consuming for documents with paragraph-format questions that need to be reformatted row-by-row.

Handling Kahoot's Character Limits

Kahoot's 95-character question limit and 60-character answer limit exist because questions and answers must be readable on a shared classroom screen from the back of the room. These limits are often exceeded by questions written in Word for a paper test or PDF worksheet - exam-style questions routinely run to 150+ characters.

Pirai AI flags questions and answers that exceed Kahoot's limits in the conversion report. Review the flagged items in the AI Survey Editor before downloading and shorten question stems and answer text to fit. A useful rule: if a question needs more than 95 characters, it is a compound question that Kahoot's game format is not suited for - consider whether the question can be split into two simpler items, or whether Kahoot is the right platform for that item.

What Kahoot's Spreadsheet Import Does Not Support

Kahoot's spreadsheet import only creates multiple choice quiz questions with up to 4 options. True/False questions must be added manually in the creator. Open-ended questions, slides (content cards), poll questions, and word cloud questions are not created by the spreadsheet import - add these manually after importing the multiple choice questions.

Images on questions and answers also cannot be set through the spreadsheet import - image assignments are made manually in the creator after import. For quizzes where image-based questions are important, import the text structure via spreadsheet, then add images to each relevant question card in the Kahoot editor.
