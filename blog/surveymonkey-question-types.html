Every SurveyMonkey Question Type Explained (2026 Guide)

Arun Raj•July 18, 2026•3 min read•Glossary
Definition

SurveyMonkey offers 15+ question types covering multiple choice, rating, matrix, ranking, text entry, demographic, NPS, slider, image-based, and file upload. Understanding which type to use - and how each maps from a survey document - is the foundation of accurate conversion from Word or PDF to SurveyMonkey.

1. Multiple Choice

Single-select question displayed as radio buttons. The most common SurveyMonkey question type. Add up to 100 answer options. Enable "Other" for open-text entry. Enable "N/A" for a not-applicable option. Set forced response to require an answer. Can trigger skip logic conditions - routing respondents to different pages based on the selected answer.

Best for: Categorical questions, yes/no, screening, routing questions.

2. Checkboxes

Multi-select question allowing respondents to select any number of options. Set a minimum or maximum number of selections required under Validation. Each option exports as a separate binary column in the response data. Use "Select All That Apply" label for clarity. The data structure (binary columns per option) requires consideration during analysis planning.

Best for: "Select all that apply" questions, feature usage, channel selection.

3. Matrix / Rating Scale

SurveyMonkey's most used question type for research. Multiple row statements rated on a shared set of column options. Configure as a Likert matrix (agreement scale), satisfaction matrix, frequency matrix, or with custom column labels. Enable row randomisation to counteract order effects - important for validated research instruments. The Matrix type in SurveyMonkey is equivalent to Qualtrics' Matrix Table question and Google Forms' Multiple Choice Grid.

Best for: Likert batteries, satisfaction attribute ratings, brand perception grids.

4. Net Promoter Score

Native NPS question type displaying the standard 0-10 scale with "Not at all likely" and "Extremely likely" endpoint labels. Automatically categorises responses into Promoters (9-10), Passives (7-8), and Detractors (0-6) in the response summary. The NPS score and segment breakdown appear automatically in the Analyze view. Use the native NPS type - not a custom rating scale - to ensure correct labelling and automatic Promoter/Passive/Detractor calculation.

Best for: Customer NPS, employee NPS (eNPS), relationship and transactional loyalty measurement.

5. Ranking

Respondents drag and drop items into order of preference or priority. Each item receives a rank number in the response data. Use for feature prioritisation research, brand preference ordering, and any question where the relative ordering of options matters more than absolute ratings. Limit to 7-8 items maximum - longer ranking lists fatigue respondents and produce unreliable data at the bottom of the list.

Best for: Feature prioritisation, brand preference ranking, importance ordering.

6. Slider

A horizontal drag-to-rate input for continuous or stepped numeric ratings. Configure the minimum, maximum, and step increment. Set starting position (left, centre, or a specific value). Labels at the endpoints. Useful for price sensitivity questions ("How much would you expect to pay?"), continuous satisfaction ratings, and any question where a numeric drag feels more intuitive than radio buttons.

Best for: Price sensitivity, willingness-to-pay, continuous satisfaction ratings.

7. Star Rating

Visual star-based rating using 1-5 or 1-10 stars. Configure number of stars and optional labels. Less common in research surveys but appropriate for customer-facing satisfaction questions where the star metaphor is familiar (product reviews, experience ratings). For research surveys requiring precise Likert measurement, the Matrix type is more appropriate.

Best for: Product ratings, experience quality for consumer-facing surveys.

8. Text Response and Comment Box

Single-line Text Response for short answers (name, email, ID). Multi-line Comment Box for open-ended feedback. Add validation to Text Response for email format, phone number, date, or numeric input. Comment Box has no character limit by default but can be restricted. These are SurveyMonkey's equivalents to Google Forms' Short Answer and Paragraph types.

Best for: Open-ended feedback, NPS follow-up verbatims, name and contact fields.

9. Dropdown

Single-select presented as a dropdown menu. Best for long option lists (countries, departments, industries) where radio buttons would take excessive vertical space. Cannot trigger skip logic - use Multiple Choice if the question needs to route respondents to different pages.

Best for: Country selection, long categorical lists, saving vertical space on mobile.

10. Date / Time

Structured date and time input with format options (MM/DD/YYYY, DD/MM/YYYY, etc.). Use for scheduling, event registration, and date-of-birth collection. Set required to ensure respondents complete the field before proceeding.

11. Demographic

A pre-built question type that collects standard demographic information (name, company, address, email, phone, city, state, zip, country) in a single form-field layout. Useful for contact data collection and event registration where multiple fields are needed together. Not appropriate for anonymous research surveys.

12. File Upload

Allows respondents to attach files to their survey response. Configure accepted file types and size limits. Files are stored in SurveyMonkey's response data. Available on paid plans.

13. Image Choice

Respondents select from images rather than text options. Use for ad creative testing, packaging evaluation, brand identity research, and any stimulus-response question where the option is visual. Configure as single or multiple image selection.

What SurveyMonkey Is Missing

Compared to Qualtrics, SurveyMonkey does not have: Constant Sum (budget allocation), Drill Down (cascading dropdowns), Side by Side matrix, Heat Map or Hotspot, Signature capture, and advanced Timing questions. For studies requiring these types, Qualtrics is more appropriate. Pirai AI converts the same document to either platform.

Frequently Asked Questions

How many question types does SurveyMonkey have?+

SurveyMonkey has 15+ question types including Multiple Choice, Checkboxes, Matrix/Rating Scale, NPS, Ranking, Slider, Star Rating, Text Response, Comment Box, Dropdown, Date/Time, Demographic, File Upload, Image Choice, and Descriptive Text. Some types are plan-restricted.

Does SurveyMonkey have a matrix question type?+

Yes. SurveyMonkey's Matrix / Rating Scale question type displays multiple row statements against shared column options in a grid format. It supports row randomisation and custom column labels. It is equivalent to Qualtrics' Matrix Table and Google Forms' Multiple Choice Grid.
