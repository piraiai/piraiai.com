What Is a Qualtrics QSF File? Format, Import, and How to Create One

Arun Raj•September 1, 2026•6 min read•Guide
Qualtrics QSF File

A QSF (Qualtrics Survey Format) file is a JSON-based file that contains the complete definition of a Qualtrics survey - all questions, answer options, question types, blocks, survey metadata, and settings. Importing a QSF file creates a complete survey in Qualtrics instantly, without building question by question in the Survey Builder. QSF is the only file format Qualtrics accepts for survey import - you cannot import a Word document, PDF, or Excel file directly into Qualtrics.

What a QSF File Contains

A QSF file is a plain text file in JSON format. Opening it in a text editor reveals a structured set of data blocks:

  • SurveyEntry: Survey ID, name, creation date, status, and general settings
  • SurveyElements: The core content - every question (QID), block (BL), survey flow (FL), embedded data (ED), and response sets
  • Questions: Each question has a QuestionType (MC, Matrix, TE, Slider, etc.), QuestionText, Choices (answer options with their codes), and display settings
  • Blocks: Survey Builder blocks that group questions together
  • SurveyFlow: The Survey Flow structure controlling the order of blocks, branching, embedded data, and randomisation

How to Import a QSF Into Qualtrics

Step 1: In Qualtrics, click the Create a new project button or go to the survey you want to replace.

Step 2: From the survey list or project creation screen, look for From a file or from an existing survey project option. Alternatively, open an existing survey and go to Tools (gear icon, top right of Survey Builder) > Import/Export > Import Survey.

Step 3: Click to browse or drag your .qsf file into the upload area.

Step 4: Click Import. Qualtrics creates a new survey with all questions, blocks, and settings from the QSF file.

After import, configure display logic, Survey Flow branching, embedded data, and quotas in the Survey Builder - these are study-specific settings not included in a newly generated QSF.

How to Export an Existing Survey as QSF

To export any Qualtrics survey as a QSF (for backup, sharing, or importing into another Qualtrics account):

Open the survey in Qualtrics > Tools (gear icon) > Import/Export > Export Survey. Select "Qualtrics Survey Format (.qsf)" and click Export. The QSF file downloads immediately.
