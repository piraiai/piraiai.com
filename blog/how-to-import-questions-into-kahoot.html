How to Import Questions into Kahoot (Spreadsheet Guide, 2026)

Arun Raj•July 18, 2026•3 min read•Glossary
Definition

Kahoot imports questions from an Excel spreadsheet (.xlsx) using a specific column structure: question text, up to four answer options, time limit in seconds, and a correct answer number. The import function is accessed from the quiz editor via the 'Import spreadsheet' button. Questions are limited to 95 characters and answers to 60 characters each.

What Kahoot's Import Supports

Kahoot supports bulk question import via Excel spreadsheet only. There is no CSV import, no Word import, no PDF import, and no plain text import. The import function accepts .xlsx files structured to Kahoot's column template, with one question per row.

Kahoot's spreadsheet import supports multiple choice questions only - up to 4 answer options per question with at least one correct answer marked. True/false questions are formatted as 2-option multiple choice. Open-ended, short answer, and fill-in-the-blank question types are not supported by Kahoot's import.

The Kahoot Spreadsheet Format

Kahoot's import spreadsheet uses the following column structure (the exact column headers must match Kahoot's template):

ColumnRequired?Limits and Notes
QuestionYesMax 95 characters including spaces
Answer 1YesMax 60 characters. At least 2 answers required.
Answer 2YesMax 60 characters
Answer 3NoMax 60 characters
Answer 4NoMax 60 characters
Time limit (seconds)Yes5-120 seconds. 20 is the Kahoot default.
Correct answerYesNumber (1-4) indicating which answer is correct. At least 1 required.
Image linkNoURL to an image to display with the question

Download Kahoot's official template from the import dialog in Kahoot's quiz editor. Use it as your base to ensure the column headers match exactly - Kahoot's import rejects spreadsheets with column headers that do not match the template.

How to Import Step by Step

1

Log into Kahoot and click Create

Go to kahoot.com. Click Create in the top navigation. Select Quiz as the game type.

2

Select Blank Canvas

Choose Blank Canvas - not one of the themed templates. This opens the quiz editor where the import function is available.

3

Click Import spreadsheet

In the bottom right of the quiz editor, click Import spreadsheet. A dialog opens with a link to download Kahoot's template and a drag-and-drop upload zone.

4

Upload your .xlsx file

Drag and drop your spreadsheet or click to browse and upload. Kahoot validates the file. If errors exist, an error message lists the specific rows and issues. Fix them in your spreadsheet and re-upload.

5

Click Continue and review

Click Continue to proceed past any non-critical warnings. Your questions appear in the Kahoot quiz editor. Add images if needed, adjust time limits per question, and click Save.

If your questions exist in a Word document, PDF, or Excel question bank (not in the Kahoot spreadsheet format), you have two routes to the correct spreadsheet format:

Manual: Download Kahoot's template. Open your source document alongside it. Copy each question into the Question column. Copy each answer into Answer 1-4. Check character counts for every item. Add time limits. Mark correct answers. For 30 questions, plan 45-60 minutes and expect to catch limit errors after a failed first import.

Troubleshooting Kahoot Import Errors

Character limit errors. The most common. A question exceeds 95 characters or an answer exceeds 60. Open your spreadsheet, find the flagged row, shorten the text, and re-upload. With Pirai AI, these are flagged before download so you fix them in the editor first.

Missing correct answer. The Correct Answer column is empty or contains an invalid value for a row. Every question requires a correct answer number (1, 2, 3, or 4). If your source document has no answer key, add correct answers in the spreadsheet or in Kahoot's editor after import.

Too few answer options. Kahoot requires at least 2 answer options per question. Questions with only one option fail. True/false questions need "True" and "False" as the two answer options.

Column header mismatch. Kahoot's import rejects spreadsheets where column headers do not exactly match the template. Always start from Kahoot's downloaded template rather than creating a spreadsheet from scratch.

Tips for Large Question Banks

Kahoot limits each spreadsheet import to 100 questions and 1MB. For question banks larger than this, split the spreadsheet into multiple files and import each as a separate quiz. You can then link quizzes in a Kahoot game collection for a longer session.

For ongoing question bank management, keep your master question bank in Excel and use Pirai AI or Kahoot's template structure as the export format. This way the source of truth stays in a document you control rather than being locked inside Kahoot's editor.

Frequently Asked Questions

How do I bulk import questions into Kahoot?+

Kahoot bulk import uses an Excel spreadsheet (.xlsx). Create your spreadsheet using Kahoot's template (downloadable from the import dialog), with one question per row and columns for question text, up to four answers, time limit, and correct answer number. In Kahoot, go to Create > Quiz > Blank Canvas > Import spreadsheet to upload the file.

What is the maximum number of questions I can import into Kahoot?+

Kahoot's spreadsheet import supports a maximum of 100 questions per upload with a 1MB file size limit. For larger question banks, split into multiple spreadsheets and create separate quizzes, or link multiple quizzes in a Kahoot collection.

Can I import questions from Google Sheets into Kahoot?+

Yes, by exporting your Google Sheet as .xlsx (File > Download > Microsoft Excel .xlsx) and then importing the .xlsx file into Kahoot. The column structure must match Kahoot's import template. If your Google Sheet is a question bank in a different format, use Pirai AI to convert it to the Kahoot template first.

Why is my Kahoot import failing?+

The most common reasons are: question text over 95 characters, answer text over 60 characters, missing correct answer in the Correct Answer column, fewer than 2 answer options, or column headers that don't match Kahoot's template. Kahoot's error message identifies the specific rows with issues. Fix them in the spreadsheet and re-upload.
