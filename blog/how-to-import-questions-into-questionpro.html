How to Import Questions Into QuestionPro From Word, PDF, or Excel

Arun Raj•August 04, 2026•5 min read•Guide
Quick Answer

QuestionPro imports survey questions from Word documents via its Add from MS Word feature. The Word document must follow a specific structure - question text formatted with heading styles and answer options as bulleted lists. Pirai AI converts your existing Word, PDF, or Excel documents into a QuestionPro-compatible Word file automatically. Upload your source document, select QuestionPro, download the formatted DOCX, and import it via QuestionPro's Add from MS Word dialog.

QuestionPro Import Options

QuestionPro provides two main routes for importing existing survey questions:

Add from MS Word - accepts a specifically formatted .docx file where question types, question text, and answer options follow QuestionPro's heading and list structure. This is the primary import route for document-based question sets.

Migration Center (QSF import) - for migrating surveys from Qualtrics. Accepts Qualtrics QSF files and imports survey structure. Note that display logic and branching are not transferred via QSF import and must be rebuilt manually.

Three Ways to Import Questions Into QuestionPro

Method 1: Manual Entry in QuestionPro Editor

Log into QuestionPro. Open or create a survey. Click Add Question. Select the question type. Enter the question text and each answer option. Set required status and other settings. Repeat for every question. Time: 3-5 minutes per question. A 40-question survey: 3-4 hours. Best for: small additions to an existing survey or question types not supported by the Word import.

Method 2: Format a Word Document and Use Add from MS Word

QuestionPro's Add from MS Word reads a .docx file structured with heading styles. Each question is a Heading 2 paragraph. Answer options are bulleted list items under the question. Question type indicators are included as part of the heading or preceding text. The document must follow QuestionPro's template structure precisely - using the wrong heading level or list style causes import failures or incorrect question type mapping.

Limitations: Matrix and grid questions have limited support through Word import. Complex question types (ranking, slider, constant sum) must be added manually after import.

Migrating From Qualtrics to QuestionPro

If you are migrating from Qualtrics to QuestionPro following a licence change at your institution, you have two routes. QuestionPro's Migration Center accepts QSF files (up to 50 at a time via API or file upload) and migrates survey structure - but does not transfer display logic. Alternatively, upload your original source documents to Pirai AI and generate a QuestionPro-formatted DOCX for each survey. Frequently Asked Questions

How do I import questions into QuestionPro from a Word document?+

QuestionPro's Add from MS Word feature imports questions from a specifically structured .docx file. To convert your existing Word document (which likely doesn't follow QuestionPro's required format), upload it to Pirai AI at platform.piraiai.com, select QuestionPro, download the formatted DOCX, and import it via Add Question > Add from MS Word in your QuestionPro survey.

Can I import a PDF into QuestionPro?+

Not directly. QuestionPro accepts Word (.docx) files via Add from MS Word, not PDFs. Upload your PDF to Pirai AI, select QuestionPro, download the formatted DOCX, and import it into QuestionPro. For scanned PDFs, enable Advanced PDF Processing for OCR.

How do I migrate Qualtrics surveys to QuestionPro?+

QuestionPro's Migration Center accepts Qualtrics QSF files via API or file upload (up to 50 surveys at a time). Survey structure is imported but display logic is not transferred and must be rebuilt. For complex instruments, upload the original source document to Pirai AI and generate a fresh QuestionPro-formatted file. See the full migration guide at /blog/migrate-qualtrics-to-questionpro.

What question types does QuestionPro's Word import support?+

QuestionPro's Add from MS Word supports Multiple Choice, Multiple Answer, Open-Ended, Matrix/Rating Scale, Dropdown, and Rank Order. NPS, Slider, Constant Sum, and other advanced types need to be added manually after the Word import.
