Create a Google Forms Quiz With Answer Key From a Document

Arun Raj•August 21, 2026•5 min read•Guide
Google Forms Quiz With Answer Key

Creating a Google Forms quiz with correct answers set manually is time-consuming - you have to enable Quiz mode, then open every question, click Add answer key, select the correct option, and set point values one by one. Pirai AI detects answer key markers in your source document and creates the Google Form in one click. Open the form, enable Quiz mode, and the correct answers are already indicated from what Pirai AI captured from your document.

How Pirai AI Detects Answer Keys in Documents

Most teachers and exam authors mark correct answers in their Word or PDF quiz documents using one of these conventions. Pirai AI detects all of them:

  • Asterisk marker: * A) The mitochondria - the asterisked option is the correct answer
  • Bold text: Answer option formatted in bold in Word - detected as correct answer
  • "ANSWER:" or "Correct:" label: A line below the options stating the correct answer letter or text
  • Underlined option: Correct answer underlined in the source document
  • Bracketed indicator: A) The mitochondria [correct]
  • Answer key section: A separate "Answer Key" section at the end of the document listing question numbers and answers

In the Pirai AI review workspace, each detected correct answer is highlighted so you can verify before the Google Form is created. Any questions where the answer key was not detected can be flagged and set manually after the form is created in Google Forms.

Creating the Quiz in Google Forms

1. Upload your quiz document at platform.piraiai.com. Word, PDF, Excel, or PowerPoint.

2. Review in the workspace. Correct answers detected from your document are highlighted. Confirm or adjust before creating the form.

3. Click Export to Google Form. Authorise with your Google account. The form is created in your Drive.

4. Enable Quiz mode in Google Forms. Open the created form. Go to Settings > Quizzes > toggle Make this a quiz on. Set point values per question. Questions where Pirai AI detected the correct answer will have the answer pre-indicated from the source document extraction.

5. Review and set remaining answers. For any questions where the answer key was not automatically detected, click Add answer key on that question and select the correct option. Save.

Google Forms Quiz Settings After Creation

Once Quiz mode is enabled, configure how students experience the quiz:

  • Release grade: Immediately after submission (self-grading) or Later, after manual review
  • Respondent can see: Missed questions, correct answers, point values
  • Shuffle question order: Settings > Presentation > Shuffle question order prevents copying
  • Limit to one response: Settings > Responses > Limit to 1 response
  • Collect email addresses: Settings > Responses > Collect email addresses for tracking

Frequently Asked Questions

Can Pirai AI detect correct answers from my quiz document?+

Yes. Pirai AI detects common answer key conventions: asterisked options, bold text, 'ANSWER:' labels, underlined options, bracketed [correct] indicators, and separate answer key sections at the end of the document. Detected correct answers appear highlighted in the review workspace before the Google Form is created.

How do I enable Quiz mode in Google Forms after Pirai AI creates the form?+

Open the created form in Google Forms. Go to Settings (gear icon) > Quizzes > toggle Make this a quiz on. Set point values for each question. For questions where Pirai AI detected the correct answer from your source document, set the answer key via the Add answer key button on each question. Save and preview.

Can I create a Google Forms quiz from a PDF exam paper with an answer key?+

Yes. Upload your PDF exam paper to Pirai AI. If the PDF contains an answer key section or uses standard correct-answer markers (asterisks, bold, 'Correct:' labels), Pirai AI detects these during extraction. Review detected answers in the workspace before clicking Export to Google Form.

What if Pirai AI does not detect the answer key in my document?+

If your document uses a non-standard answer key format that Pirai AI does not detect, the Google Form is created with all question and answer options in place. Enable Quiz mode in Google Forms after creation and set correct answers manually using the Add answer key button on each question. The question structure is already built - only the answer key settings need manual configuration.
