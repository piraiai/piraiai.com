How to Import Questions Into REDCap From Word, PDF, or Excel

Arun Raj•August 04, 2026•5 min read•Guide
Quick Answer

REDCap does not accept Word documents, PDFs, or Excel files directly. The only way to import questions into REDCap in bulk is via a Data Dictionary CSV - a structured spreadsheet defining every field's name, type, label, and answer choices in REDCap's column format. Pirai AI generates this Data Dictionary CSV from any source document. Upload your document, select REDCap, download the CSV, and import it via Project Setup > Data Dictionary > Upload File > Commit Changes.

Why REDCap Uses a Data Dictionary (Not a Question Import)

REDCap stores survey content as fields in an instrument - not as questions in a form. Each field has a variable name, field type, field label (the question text), answer choices in pipe-delimited format, validation rules, required status, and optional branching logic. The Data Dictionary CSV defines all of these properties for every field in one file. It is how REDCap structures its internal database and how it enables the export, sharing, and validation of research instruments across institutions.

This means importing questions into REDCap is fundamentally different from importing into Google Forms, SurveyMonkey, or Qualtrics - you are building a structured database specification, not filling a form builder.

Three Ways to Import Questions Into REDCap

Method 1: Manual Entry in the Online Designer

Log into REDCap. Open your project. Go to Project Setup > Online Designer. Click on an instrument. Click Add Field. Select the field type, enter the variable name, paste the field label, add answer choices (one per line in the dialog), set validation and required status. Click Save. Repeat for every field.

Time: 3-5 minutes per radio/checkbox field with multiple options. 15+ minutes per matrix row. A 40-item validated scale: 3-5 hours. Transcription risk: typing errors alter field labels - critical problem for validated instruments where exact wording determines psychometric validity.

Method 2: Build the Data Dictionary CSV Manually

Download the Data Dictionary template from Project Setup > Data Dictionary > Download the current Data Dictionary. Open in Excel. Add one row per field, filling columns: Variable Name, Form Name, Field Type, Field Label, Choices (pipe-delimited), Required Field?, Branching Logic. Save as CSV. Upload via Project Setup > Data Dictionary > Upload File > Commit Changes. Faster than Online Designer for experienced REDCap users - still 2-3 hours for a 40-field instrument when formatting choices manually.

After Import: What to Configure in REDCap

After Commit Changes, all fields appear in the Online Designer. Configure these manually after import: Branching logic - use the drag-and-drop Logic Builder in the Online Designer, using variable names assigned at import. Calculated fields - add composite score formulas (e.g. PHQ-9 total) using REDCap's expression syntax. Field validation - set date, integer, and numeric validation rules on text fields. Survey settings - configure the survey queue, auto-continue, and respondent-facing display options in the Survey Settings section.

What is a REDCap Data Dictionary and why is it needed for import?+

A REDCap Data Dictionary is a CSV file that defines every survey field's variable name, form name, field type, field label, answer choices, validation, and branching logic. It is the only supported bulk import format in REDCap - there is no question paste feature or document upload. Every field in a REDCap project is defined by its Data Dictionary.

Can I import a validated clinical instrument into REDCap from a PDF?+

Yes. Upload the instrument PDF to Pirai AI, select REDCap, download the Data Dictionary CSV, and import via Project Setup > Data Dictionary > Upload File. The exact item wording from the PDF is preserved verbatim in the Field Label column - critical for maintaining the psychometric properties of validated scales. For scanned PDFs, enable Advanced PDF Processing for OCR.

How long does it take to import a 40-question survey into REDCap?+
