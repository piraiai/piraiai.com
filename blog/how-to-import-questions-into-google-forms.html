How to Import Questions Into Google Forms (All Methods, 2026)

Arun Raj•August 04, 2026•5 min read•Guide
One-click Google Forms conversion is here
Pirai AI now creates Google Forms directly in your Drive - no Script Editor, no pasting code, no add-on. Try the one-click method
Quick Answer

Google Forms has one native import: copying questions from another Google Form in your Drive. For everything else - Word documents, PDFs, Excel files, Qualtrics surveys, SurveyMonkey surveys, or Microsoft Forms questions - you need a third-party conversion step. Pirai AI converts any of these sources to a Google Apps Script that builds all questions in Google Forms automatically, with no Drive access required.

Method 1: Import From Another Google Form (Native)

The only built-in import Google Forms supports. Open your destination form. In the right-hand floating toolbar, click the circle-with-arrow Import Questions icon. A dialog shows Google Forms in your Drive. Select the source form, choose which questions to import, click Import questions. Questions are added at the bottom of your current form.

Best for: questions already in a Google Form in your Drive. Cannot be used for: Word documents, PDFs, Excel, or other survey platforms.

Method 2: Import From Word, PDF, or Excel

Google Forms has no native document import. To import questions from a Word document, PDF, or Excel file, convert the document to a Google Apps Script using Pirai AI, then run it in a blank Google Form.

  1. Upload at platform.piraiai.com - Word (.docx), PDF (text or scanned), or Excel (.xlsx)
  2. Select Google Forms and download the Apps Script
  3. Open a blank Google Form - three-dot menu > Script editor > paste script > Run

All questions appear instantly. Matrix and Likert questions are converted to Multiple Choice Grid. No Drive access granted at any point. See the full guide: how to add questions to Google Forms from a document.

Method 3: Import From Qualtrics

Export your Qualtrics survey as a QSF file (Survey tab > Tools > Import/Export > Export Survey). Upload the QSF to Pirai AI, select Google Forms, download the Apps Script, and run it in a blank Google Form. All questions from the Qualtrics survey are created in Google Forms automatically.

What transfers: question text, question types, answer options, and section structure. What doesn't transfer: Qualtrics display logic (Google Forms only supports section-level branching), embedded data, and quota settings. See the full guide: how to import questions into Qualtrics.

Method 4: Import From SurveyMonkey

SurveyMonkey does not export surveys in a format Google Forms can read natively. The most reliable route: export your SurveyMonkey survey as a PDF (Print Survey option in SurveyMonkey), upload the PDF to Pirai AI, select Google Forms, and run the Apps Script. Alternatively, use SurveyMonkey's Word export if available on your plan.

See the full guide: how to import questions into SurveyMonkey.

Method 5: Import From Microsoft Forms

Microsoft Forms does not have a direct export to Google Forms format. Export your Microsoft Form questions by going to the form > three-dot menu > Print > Save as PDF, or use the Download a copy option where available. Upload the PDF to Pirai AI, select Google Forms, and run the Apps Script.

See the full guide: how to import questions into Microsoft Forms.

Method 6: Import From LimeSurvey

Export your LimeSurvey survey as an LSS file (Survey menu > Export > Survey archive). Upload the LSS file to Pirai AI, select Google Forms, and run the Apps Script in a blank Google Form.

See the full guide: how to import questions into LimeSurvey.

Method 7: Import From REDCap

Export your REDCap instrument as a Data Dictionary CSV (Project Setup > Data Dictionary > Download the current Data Dictionary). Upload the CSV to Pirai AI, select Google Forms, and run the Apps Script in a blank Google Form.

See the full guide: how to import questions into REDCap.

What Never Transfers Regardless of Method

Branching logic: Google Forms only supports section-based branching - one route depending on a single answer. Complex multi-condition display logic from Qualtrics, SurveyMonkey, or LimeSurvey must be rebuilt manually as section branching in Google Forms after import. Matrix questions: Pirai AI converts these to Multiple Choice Grid, but most other methods drop them entirely. Calculated scores: Scoring logic must be rebuilt manually in Google Forms Quiz mode after import.

Frequently Asked Questions

How do I import questions into Google Forms from Word?+

Google Forms has no native Word import. Upload your Word document to Pirai AI at platform.piraiai.com, select Google Forms, download the Apps Script, open a blank Google Form, go to the three-dot menu, select Script editor, paste the script, and run it. All questions appear automatically.

Can Google Forms import from Qualtrics?+

Not natively. Export your Qualtrics survey as a QSF file (Survey tab > Tools > Import/Export > Export Survey), upload the QSF to Pirai AI, select Google Forms, download the Apps Script, and run it in a blank Google Form. Question text, types, and answer options transfer. Display logic must be rebuilt as section branching in Google Forms.

Does Google Forms have a bulk import feature?+

Google Forms has one native bulk import: copying questions from another Google Form using the Import Questions button (circle-with-arrow icon in the right toolbar). For all other sources - Word, PDF, Excel, Qualtrics, SurveyMonkey, Microsoft Forms, LimeSurvey, REDCap - use Pirai AI to convert the source to a Google Apps Script, then run it in a blank Google Form.

Can I import questions from Excel into Google Forms?+

Not natively. Upload your Excel (.xlsx) file to Pirai AI at platform.piraiai.com, select Google Forms, download the Apps Script, and run it in a blank Google Form via the Script Editor (three-dot menu > Script editor).

What question types are preserved when importing into Google Forms?+

Multiple Choice, Checkboxes, Short Answer, Paragraph, and Multiple Choice Grid (matrix) are all created by Pirai AI's Apps Script. Likert scale batteries are converted to Multiple Choice Grid. NPS, Ranking, Rating, and File Upload question types do not exist in Google Forms and cannot be imported - these need to be added manually as the closest Google Forms equivalent after import.
