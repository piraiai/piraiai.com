How to Import Questions Into Moodle From Word, PDF, or Excel

Arun Raj•August 04, 2026•5 min read•Guide
Quick Answer

Moodle cannot import Word documents or PDFs directly into its question bank. Questions must be formatted in a text-based import format - primarily AIKEN (.txt) for multiple choice questions. Pirai AI converts your Word, PDF, or Excel document to a correctly formatted AIKEN .txt file with UTF-8 encoding, proper capitalisation, and the exact syntax Moodle requires. Import via Question bank > Import > Aiken format.

Moodle's Question Import Formats

Moodle supports several text-based import formats for its question bank. The two practical options for document-based conversion are:

AIKEN format - the simplest. A plain text .txt file where each multiple choice question has the question on one line, lettered answers on separate lines, and ANSWER: at the end. Only supports single-answer multiple choice. Fast to generate and import.

GIFT format - more complex. Supports multiple choice, true/false, short answer, numerical, matching, and essay questions. Requires learning the GIFT syntax for each question type. More powerful but error-prone to write manually.

Pirai AI generates AIKEN format. For quiz banks that are primarily multiple choice - the most common case for classroom assessments - AIKEN covers the bulk of the import. Non-MCQ questions are added manually after import.

Three Ways to Import Questions Into Moodle

Method 1: Manual Entry in Moodle Question Bank

Go to your Moodle course. Gear menu > More > Question bank > Add > a new question. Select the question type, enter all fields, save. Supports every Moodle question type. Time: 3-7 minutes per question. A 40-question MCQ bank: 3-4 hours.

Method 2: Format AIKEN .txt Manually

Open a text editor. Format each question to AIKEN syntax. Save as .txt with UTF-8 encoding. Import via Moodle Question bank > Import > Aiken format. The AIKEN format requires precise syntax:

What is the powerhouse of the cell?
A. Nucleus
B. Mitochondria
C. Ribosome
D. Golgi apparatus
ANSWER: B

Which planet is closest to the Sun?
A. Venus
B. Earth
C. Mercury
D. Mars
ANSWER: C

The word ANSWER must be all capitals. There must be a space after the colon. Questions must be separated by a blank line. The file must be UTF-8 encoded - ANSI encoding causes failed imports.

Why AIKEN Imports Fail (and How to Fix Them)

No questions imported / blank result: File saved as ANSI instead of UTF-8. Re-save the .txt with UTF-8 encoding (Notepad: Save As > Encoding: UTF-8). Correct answer not recognised: The ANSWER: line is lowercase or missing a space. Must be exactly ANSWER: B - uppercase, colon, one space, letter. Smart quotes causing parsing errors: Word-sourced content often contains curly quote characters. Paste through a plain text editor to strip them before saving. Frequently Asked Questions

How do I import questions into Moodle from a Word document?+

Moodle cannot import Word files directly. What format do I need to import questions into Moodle?+

Moodle's most practical import format for document-based question sets is AIKEN (.txt) - a plain text format for single-answer multiple choice questions. GIFT (.txt) supports more question types but is more complex to write. Pirai AI generates AIKEN format from Word, PDF, and Excel documents with correct UTF-8 encoding and ANSWER: syntax.

Why is my AIKEN import failing in Moodle?+

Common causes: (1) ANSWER: is lowercase - must be all capitals; (2) file is ANSI encoded instead of UTF-8 - resave with UTF-8 encoding; (3) smart curly quotes from Word - paste through Notepad to strip them; (4) question text spans multiple lines - must be on one line; (5) missing blank line between questions. Pirai AI's AIKEN output avoids all five of these issues automatically.

Can I import multiple answer questions into Moodle using AIKEN?+

No. AIKEN only supports single-answer multiple choice. Multiple answer questions (select all that apply) must be added manually in Moodle's question editor as Multiple Choice with multiple allowed answers, or imported using GIFT format.

How do I import questions into the Moodle question bank and then use them in a quiz?+

First import the questions: Question bank > Import > Aiken format > upload .txt > Import > Continue. Questions appear in the question bank. Then build the quiz: Add activity > Quiz in your course. Open the quiz, go to Edit quiz, click Add > from question bank, select the imported questions, and save. Configure time limit, grading, and attempt settings in the quiz settings.
