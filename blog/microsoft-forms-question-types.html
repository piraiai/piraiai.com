Every Microsoft Forms Question Type Explained (2026 Guide)

Arun Raj•July 18, 2026•3 min read•Glossary
Definition

Microsoft Forms has 10 question types including native Likert scale, NPS, and Ranking types not available in Google Forms. Understanding which type to use - and the important limitation around matrix questions in Quick Import - is essential for anyone deploying surveys through Microsoft 365.

1. Choice

The standard single or multiple selection question. Set to single answer (radio buttons) or multiple answers (checkboxes) using the toggle in the question settings. Add up to 200 answer options. Enable shuffle to randomise option order per respondent. For quiz mode, mark one or more correct answers and assign points. Choice questions can trigger section branching - routing respondents to different sections based on their selection.

Best for: Any categorical question, yes/no, screening questions, quiz MCQ.

2. Text (Short and Long Answer)

A text entry field for open-ended responses. Toggle between short answer (single line) and long answer (multi-line) in the question settings. Add restrictions to accept only numbers, or limit character count. Short answer is appropriate for names, identifiers, and brief responses. Long answer is appropriate for qualitative feedback, open comments, and NPS follow-up questions.

Best for: Open-ended feedback, follow-up questions after a rating, name and contact fields.

3. Rating

A visual star rating question with 1-10 stars configurable. Add labels for the low and high ends. Different from a Likert scale - Rating displays stars rather than labelled scale points. Use for customer satisfaction questions where a visual star format is preferred over a numeric or labelled scale. For research-grade Likert items, use the dedicated Likert question type instead.

Best for: App store-style satisfaction, product ratings, experience quality ratings.

4. Date

A date picker for collecting date input from respondents. Format varies by locale. Use for appointment scheduling, event registration date fields, and any date-structured data collection. For date of birth collection requiring validation, the Text question with number restriction may be more controllable.

Best for: Appointment scheduling, event registration, birth year collection.

5. Ranking

A drag-and-drop question where respondents rank items in order of preference or priority. Respondents drag items into their preferred order. This is a native question type in Microsoft Forms that Google Forms does not have - Google Forms requires a workaround using numbered multiple choice questions to approximate ranking. Use for feature prioritisation, preference ordering, and importance ranking questions.

Best for: Feature prioritisation, brand preference ranking, importance ordering, top-N selection.

6. Likert

A native Likert scale question type displaying multiple statements against a shared set of scale points in a grid layout. Add statements as rows and configure the scale columns (the scale label options are preset: Agreement, Frequency, Importance, Quality, Satisfaction - or custom). This is Microsoft Forms' closest equivalent to Google Forms' Multiple Choice Grid, but with pre-configured scale label sets for common Likert dimensions.

Important note: The Likert question type is not importable via Quick Import from a Word document. It must be created manually in the Forms editor. When Pirai AI converts a matrix/Likert battery from a document, it expands items to individual Choice questions for Quick Import compatibility. You can then manually convert these to a Likert question in the editor if the grid format is preferred.

Best for: Employee satisfaction batteries, course evaluation scales, agreement-scale surveys built manually in the editor.

7. Net Promoter Score (NPS)

A native NPS question type pre-configured with the 0-10 scale and standard endpoint labels ("Not at all likely" / "Extremely likely"). Microsoft Forms is one of the few free survey tools with a native NPS type - Google Forms requires a Linear Scale workaround. Responses display NPS score breakdowns (Promoter/Passive/Detractor) in the Forms response summary. Use for customer satisfaction and employee loyalty measurement within an M365 environment.

Best for: Customer NPS programmes, employee NPS (eNPS), loyalty measurement for internal and external audiences.

8. File Upload

Allows respondents to attach files to their form submission. Files are stored in OneDrive for Business or SharePoint linked to the form owner's account. Respondents do not need a Microsoft account to upload files (unlike Google Forms file upload, which requires a Google account). Set allowed file types and size limits in the question settings. Use for evidence submission, assignment upload, and document collection workflows.

Best for: Assignment submission, document collection, evidence upload in compliance workflows.

9. Section

A structural element that divides the form into pages. Each section is a separate page for respondents. Section branching routes respondents to different sections based on their answer to a Choice question - Microsoft Forms' equivalent of Google Forms' section-based branching. Configure branching by clicking the three-dot menu on a Choice question and selecting "Add branching."

Best for: Long surveys requiring pagination, surveys with screening questions routing to different content paths.

The Matrix Grid Limitation in Quick Import

Microsoft Forms supports the Likert question type as its matrix grid implementation, but this type cannot be included in Quick Import from a Word document. Only Choice, Text, Rating, Date, and Ranking questions import cleanly via Quick Import.

When Pirai AI converts a survey document with matrix or Likert battery questions to Microsoft Forms, it expands each matrix row into an individual Choice question. All items are preserved - nothing is lost - but the visual grid format is not maintained through the import. After import, you can manually group the expanded Choice questions into a Likert question type in the Forms editor if the grid display is important for your survey.

For surveys where matrix presentation is critical (research instruments requiring the grid format for validated scale administration), consider converting to Qualtrics or REDCap instead, where matrix types import correctly.

Frequently Asked Questions

How many question types does Microsoft Forms have?+

Microsoft Forms has 10 question types: Choice (single and multi), Text (short and long), Rating, Date, Ranking, Likert, Net Promoter Score, File Upload, Section, and image/video display elements. The native Likert, NPS, and Ranking types are not available in Google Forms.

Does Microsoft Forms have a matrix question type?+

Microsoft Forms has a Likert question type that functions as a matrix - multiple statements rated on a shared scale in a grid. However, the Likert type cannot be imported via Quick Import from a Word document. It must be created manually in the Forms editor. When converting documents with Pirai AI, matrix rows are expanded to individual Choice questions for import compatibility.

Does Microsoft Forms have a native NPS question type?+

Yes. Microsoft Forms includes a dedicated Net Promoter Score question type pre-configured with the 0-10 scale and standard 'Not at all likely' / 'Extremely likely' endpoint labels. The response summary automatically shows Promoter, Passive, and Detractor breakdowns.

Can I import Microsoft Forms question types from a Word document?+

Via Quick Import, Microsoft Forms accepts Choice, Text, Rating, Date, and Ranking question types. Likert and NPS questions must be created manually in the editor after import. Pirai AI converts matrix/Likert questions to individual Choice questions for Quick Import compatibility, with a note to manually convert to the Likert type in the editor if the grid format is needed.
