How to Turn Questions Into a Google Form (Without Retyping Each One)

Arun Raj•July 31, 2026•5 min read•Guide
Quick Answer

If your questions are in a Word, PDF, or Excel document: upload to platform.piraiai.com, select Google Forms, download the Apps Script, paste into the form Script Editor (three-dot menu), click Run. Done in under 3 minutes - no Drive access granted and no add-on installed. If your questions are already in another Google Form in your Drive: use the native Import Questions button (arrow icon in the right toolbar).

Why Google Forms Has No Native Document Import

Google Forms can import questions from another existing Google Form in your Drive. It cannot import from Word documents, PDFs, Excel files, or Google Docs. There is no upload button, no paste-from-document feature, and no drag-and-drop for external file content in the Google Forms editor.

This means every time you want to turn an existing document full of questions into a Google Form, you are forced to either retype each question manually or find a third-party approach. For a 30-question survey, manual retyping takes 45-90 minutes.

Method 1: Native Import from an Existing Google Form

The only built-in import Google Forms supports. Open the destination Google Form. In the right-hand floating toolbar, click the circle-with-arrow icon. Select the source form from your Drive, choose questions, click Import questions. Limitation: Only works if the source is already a Google Form - not for Word, PDF, or Excel files.

Method 2: Manual Copy-Paste

Open your document and Google Forms side by side. For each question: click + to add a question, select the type, paste the text, add each answer option. About 90 seconds per multiple choice question. Best when: under 10 simple questions. Fails completely for matrix or Likert questions where each row requires separate creation.

Method 3: Google Workspace Add-On

Tools like Automagical Forms and Jotform AI Form Builder run inside Google Forms or Google Docs and read a document to generate questions. Require granting Drive access. Work well for simple multiple choice from Google Docs. Limitation: Most drop matrix questions or convert each matrix row to a separate standalone question, losing the grid format. Only output to Google Forms.

Pirai AI reads your Word, PDF, Excel, or CSV document and generates a Google Apps Script. You paste and run the script in the Google Forms Script Editor. The form is built by your own Google account. No Drive access granted to any third party.

The Matrix Question Problem

If your document has matrix questions - multiple statements rated on the same scale in a grid - most methods either drop them or convert each row to a separate standalone question. Pirai AI converts matrix questions to Google Forms' Multiple Choice Grid type, preserving all row statements and column scale labels from the source document. For research surveys, patient satisfaction instruments, and engagement surveys where matrix questions are standard, this distinction matters significantly.

Frequently Asked Questions

Can you import questions into Google Forms from Word?+

Not natively. Google Forms cannot open Word files. To import from a Word document, use Pirai AI: upload at platform.piraiai.com, select Google Forms, download the Apps Script, paste into the form Script Editor (three-dot menu), and run it. All questions appear automatically.

How do I turn a PDF into a Google Form?+

Upload the PDF to Pirai AI at platform.piraiai.com, select Google Forms, download the Apps Script. Open a blank Google Form, three-dot menu, Script editor, paste and run. For scanned PDFs, enable Advanced PDF Processing for OCR.

Does Google Forms have an import questions feature?+

Yes, but only for importing from other Google Forms in your Drive. The Import Questions button (arrow icon in the right toolbar) copies questions from an existing Google Form. It cannot import from Word, PDF, Excel, or Google Docs.

Can I import Likert scale questions from a document into Google Forms?+

Yes, with Pirai AI. Likert batteries from your document are converted to Multiple Choice Grid questions in Google Forms, preserving all row statements and column scale labels. Most add-ons flatten Likert batteries into individual questions or drop them.

How do I transfer quiz questions from Word to Google Forms?+

Upload your Word quiz file to Pirai AI, select Google Forms, download and run the Apps Script. Then enable Quiz mode in Settings to turn the imported questions into a self-grading quiz.
