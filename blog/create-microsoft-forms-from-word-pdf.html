How to Create a Microsoft Form From a Word or PDF Document (2026)

Arun Raj•August 02, 2026•5 min read•Guide
Quick Answer

Microsoft Forms accepts Word and PDF files via its Quick Import feature. Go to forms.office.com, create a new form, click the three-dot menu (...), select Import questions, and upload your file. However, Quick Import only supports Multiple Choice and Open Text questions - Likert scales, matrix grids, NPS, and Ranking questions are flagged as unsupported. For complex surveys, use Pirai AI to pre-process the document so that more question types import cleanly.

Microsoft Forms Actually Accepts Word and PDF Files

Unlike Google Forms (no document import) and Qualtrics (only a specific Advanced Format DOCX), Microsoft Forms has a genuine Quick Import that reads standard Word documents and PDFs. This is a meaningful advantage for M365 users - you can take a survey document you already have and import it directly without reformatting.

The catch is question type coverage. Quick Import creates Multiple Choice and Open Text questions reliably. Everything else requires post-import manual addition. For surveys that are mostly multiple choice with a few open text questions, Quick Import works well on its own. For research surveys with Likert batteries, matrix grids, or NPS questions, plan on 20-40 minutes of manual question addition after the import step.

Method 1: Direct Quick Import (Best for Simple Surveys)

Step 1. Go to forms.office.com. Sign in with your Microsoft account. Click New Form.

Step 2. Click the three-dot menu (...) in the top right. Select Import questions. (On some tenants this appears as a Quick Import button at the top of the editor.)

Step 3. Click Upload from device. Select your Word (.docx) or PDF file. Choose Form or Quiz. Click Next.

Step 4. Wait for conversion. When complete, click Start Review.

Step 5. In Start Review, work through any flagged items - Missing content, Uncertain conversion, or Unsupported question type. Resolve each flag. Click Done.

Tips for cleaner import: Structure answers as numbered or lettered options on separate lines (1. Yes 2. No 3. Maybe). Remove tables, images, and complex formatting before uploading. Keep file size under 10MB.

Method 2: Pirai AI Pre-Processing + Quick Import (For Complex Surveys)

For surveys with Likert scales, matrix questions, or mixed question types, upload to Pirai AI first. Pirai AI expands matrix and Likert questions into individual Choice questions (Quick Import-compatible), structures the document to Quick Import's formatting requirements, and removes non-importable elements.

  1. Upload at platform.piraiai.com - Word, PDF, or Excel
  2. Select Microsoft Forms. Download the output file.
  3. Use Quick Import in Microsoft Forms to import the Pirai AI output file
  4. Start Review - significantly fewer flagged items than importing the raw source
  5. Add NPS, Ranking, Rating, Date, and File Upload questions manually where needed

Method 3: Manual Entry (For Small Forms)

For forms with under 10 questions, manual entry in Microsoft Forms is faster than configuring an import. Click Add new, select the question type, and paste each question. For forms that need native Likert, NPS, or Ranking question types specifically - these cannot be imported by Quick Import anyway - manual entry is always required for those types regardless of import method.

Creating a Quiz in Microsoft Forms From a Document

At the Quick Import step, select Quiz instead of Form to create a self-grading quiz. After import, enable Quiz mode in Settings if you started with Form and change your mind. For each Multiple Choice question, click Answer key to mark the correct answer and assign points. Microsoft Forms auto-grades Multiple Choice, Checkboxes, Dropdown, and Short Answer questions in Quiz mode. Open text / Paragraph questions require manual grading.

For quiz documents where answer keys are embedded in the source (e.g. asterisks or "(correct)" markers on correct answers), note the correct answers before importing and set the answer keys in the editor during Start Review.

Frequently Asked Questions

Can Microsoft Forms import a Word document?+

Yes. Microsoft Forms' Quick Import feature accepts Word (.docx) and PDF files. Access it via the three-dot menu (...) > Import questions in the form editor. Quick Import supports Multiple Choice and Open Text question types. Likert scales, matrix grids, NPS, Ranking, Rating, File Upload, and Date questions are flagged as unsupported and require manual addition.

How do I create a Microsoft Form from a PDF?+

In Microsoft Forms, click the three-dot menu > Import questions. Upload your PDF. Choose Form or Quiz. Click Start Review to see the imported questions and any flagged items. For scanned PDFs with limited OCR quality, upload to Pirai AI first to extract and structure the content before importing to Microsoft Forms.

Why can't I import all question types into Microsoft Forms?+

Microsoft Forms Quick Import was designed primarily for simple quizzes and surveys. The Quick Import parser only creates Multiple Choice and Open Text questions reliably. More complex types like Likert, NPS, Ranking, and Rating require the native MS Forms question editor because they have unique UI components that cannot be parsed from document formatting.

Can I create a quiz in Microsoft Forms from a Word document?+

Yes. At the Quick Import step, select Quiz instead of Form. After import, click Answer key on each Multiple Choice question to mark the correct answer and set point values. MS Forms auto-grades Multiple Choice, Checkboxes, and Short Answer questions. Open text questions require manual grading.

What is the difference between creating a Form and a Quiz in Microsoft Forms?+

Both are created in Microsoft Forms. A Form collects responses without scoring. A Quiz has Quiz mode enabled - each question can have a correct answer and point value, respondents see their score after submission, and teachers see per-question correctness data. Select at the Quick Import step, or enable in Settings > Quizzes after creating a Form.
