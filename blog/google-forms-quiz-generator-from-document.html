Answer Key Detection

Pirai AI reads answer key markers from your document automatically. Common formats it detects:

  • Bolded correct answer - e.g. A. Paris B. London C. Berlin
  • Asterisk or star marker - e.g. *A. Paris or A. Paris*
  • Answer key section at the end - a list like "1.A 2.C 3.B 4.D"
  • Underlined correct answer in the options
  • Parenthetical notation - e.g. A. Paris (correct)

Detected correct answers appear in the Pirai AI editor for review before export. If your document uses a format not listed above, mark correct answers manually in the editor before exporting. After export, open each question in Google Forms, click Answer Key, confirm the correct option, and set point values.

Question Types Generated

Multiple Choice

Auto-graded. Detected from lettered or numbered option lists. Most common quiz question type.

Checkboxes

Auto-graded. Detected from select-all-that-apply questions with multiple correct answers.

Short Answer

Auto-graded for exact text match. Good for fill-in-the-blank and single word responses.

Paragraph

Requires manual grading. Detected from essay question prompts and long-form response fields.

Multiple Choice Grid

Detected from matrix and Likert table structures. Rows become sub-questions, columns become options.

Dropdown

Detected from dropdown-formatted option lists. Reduces visual clutter for long option sets.
