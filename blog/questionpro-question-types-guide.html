QuestionPro Question Types: Complete Guide With Examples

Arun Raj•September 1, 2026•6 min read•Guide
QuestionPro Question Types

QuestionPro offers a comprehensive range of question types from standard multiple choice to advanced research methodologies like MaxDiff and conjoint analysis. Selecting the right question type for each survey item directly affects data quality, analytical capability, and the respondent experience. This guide covers the question types used most commonly in research and market research surveys, with examples of when to use each.

Standard Survey Question Types

Single Choice: Respondent selects one option from a list (radio buttons). The most common question type in surveys. Use for: gender, age group, education level, any question with mutually exclusive single-answer options.

Multiple Choice: Respondent selects one or more options (checkboxes). Use for: "select all that apply" questions, multi-attribute selection, product ownership, media consumption.

Open Text: Free-form text entry. Sub-types include single-line (short answer) and multi-line comment box (long answer). Use for: verbatim feedback, explanations, "other please specify" fields, qualitative open-ended questions.

Dropdown: Options presented in a dropdown list. Use for: long option lists where radio buttons would require excessive scrolling (countries, age in years, product categories).

Scale and Rating Question Types

Rating Scale: Items rated on a defined scale, presented as horizontal radio buttons or buttons. Use for: satisfaction (Very Dissatisfied to Very Satisfied), agreement (Strongly Disagree to Strongly Agree), importance (Not at all to Extremely), frequency (Never to Always). The most versatile scale type for general research.

Net Promoter Score (NPS): 0-10 recommendation likelihood scale with promoter/passive/detractor scoring built in. Use for: customer loyalty measurement, brand tracking, employee engagement measurement. QuestionPro's NPS question includes automatic Promoter/Passive/Detractor categorisation and NPS score calculation.

Slider: Continuous drag-and-drop scale. Use for: visual analog scales, percentage allocation, precise continuous measurement where discrete steps add artificial anchoring.

Semantic Differential: Bipolar scale with opposing attribute labels at each end (Fast--Slow, Modern--Traditional). Use for: brand image measurement, product perception, concept testing with opposing attribute pairs.

Grid and Matrix Question Types

Matrix / Grid: Multiple row items each rated against the same set of column scale options. The standard format for Likert scale batteries in research surveys. Use for: attitude scales, attribute evaluations, multi-item questionnaire batteries from validated instruments.

Rank Order: Respondents rank items in order of preference or priority by dragging or assigning numeric ranks. Use for: feature prioritisation, message testing, brand preference ordering.

Constant Sum: Respondents allocate a fixed total (100 points or 100%) across options. Use for: budget allocation, time distribution, share of wallet estimation.

Advanced Research Question Types

MaxDiff (Best-Worst Scaling): Respondents choose the best and worst from sets of attributes. Produces a utility or importance score for each attribute. Use for: feature prioritisation, message testing, brand element evaluation where forced trade-offs produce more discriminating data than rating scales.

Conjoint Analysis: Tests combinations of product features at different levels to measure preference and willingness to pay. Use for: product development research, pricing research, feature combination optimisation.

Van Westendorp Price Sensitivity: Four price questions producing a price sensitivity meter. Use for: pricing research and willingness-to-pay estimation.

Frequently Asked Questions

What question types does QuestionPro offer?+

QuestionPro offers Single Choice, Multiple Choice, Open Text, Dropdown, Rating Scale, Net Promoter Score, Slider, Semantic Differential, Matrix/Grid, Rank Order, Constant Sum, MaxDiff, Conjoint Analysis, and Van Westendorp, among others. The Research and Advanced plans unlock the full range of advanced types.

What is the difference between Rating Scale and Matrix in QuestionPro?+

Rating Scale is a single item rated on a defined scale (one question, one row of response options). Matrix presents multiple row items all rated against the same set of scale columns in a grid - it is the standard format for multi-item Likert scale batteries. Use Matrix when you have several items to rate on the same scale; use Rating Scale for a single-item rating.

Does QuestionPro have NPS (Net Promoter Score)?+

Yes. QuestionPro has a dedicated NPS question type with the standard 0-10 scale and automatic Promoter/Passive/Detractor categorisation and NPS score calculation. It integrates with QuestionPro's CX features for closed-loop follow-up workflows.
