LimeSurvey DB Version 5 vs 6: Which to Choose for LSS Import

Arun Raj•August 28, 2026•6 min read•Guide
LimeSurvey DB Version 5 vs 6

LimeSurvey LSS files contain a database schema version number (DB version) that must match your LimeSurvey installation. DB version 5 is compatible with LimeSurvey 3.x. DB version 6 is compatible with LimeSurvey 4.x and 5.x. Using the wrong DB version is the single most common cause of LimeSurvey import errors. This guide explains the difference, how to identify your version, and how to fix a mismatch.

What Is the DB Version?

The DB version in a LimeSurvey LSS file refers to the internal database schema version LimeSurvey uses to store survey structures. As LimeSurvey has evolved, the internal database structure has changed - fields have been added, renamed, and removed. An LSS file built for one schema version cannot be imported cleanly into a LimeSurvey installation running a different schema version.

LSS files contain the DB version in the XML header: <LimeSurveyDocType>Survey</LimeSurveyDocType> and <DBVersion>500</DBVersion> (for DB version 5) or <DBVersion>600</DBVersion> (for DB version 6). Pirai AI lets you select the correct version before downloading the LSS.

How to Check Your LimeSurvey Version

Method 1 - Admin panel: Log in to your LimeSurvey administration interface. Click your username in the top right corner, or go to Help > About LimeSurvey. The full version number is displayed (e.g. "LimeSurvey 5.3.35+220817").

Method 2 - URL path: Some self-hosted installations display the version in the admin URL structure, though this is less reliable than the About page.

Method 3 - Ask your IT team: If you access LimeSurvey through your institution's IT portal, your Rechenzentrum or IT department will know the installed version.

What Happens With the Wrong DB Version

If you import an LSS built for DB version 5 into a LimeSurvey 4.x or 5.x installation (which expects DB version 6):

  • LimeSurvey may display an error message: "This file was created for an older version of LimeSurvey"
  • Or the import appears to succeed but creates a survey with no questions - a blank survey
  • Or individual question types fail to import correctly with missing answer options

Fix: Return to Pirai AI, regenerate the LSS selecting the correct DB version for your installation, and re-import. The regeneration takes seconds.

When exporting to LimeSurvey in Pirai AI, a DB version selector appears before download. Select 5 for LimeSurvey 3.x or 6 for LimeSurvey 4.x and 5.x. If you are unsure, select 6 - it covers the majority of current LimeSurvey installations worldwide. Both versions are available for the same converted document without re-uploading.

Frequently Asked Questions

What is the difference between LimeSurvey DB version 5 and 6?+

DB version 5 is compatible with LimeSurvey 3.x. DB version 6 is compatible with LimeSurvey 4.x and 5.x. The DB version number refers to LimeSurvey's internal database schema version, which changed between major application versions. Using the wrong DB version for your installation causes import errors or creates a blank survey.

How do I find my LimeSurvey version to choose the right DB version?+

Log in to your LimeSurvey admin panel and go to Help > About LimeSurvey. Your full version number is displayed (e.g. LimeSurvey 5.3.35). Version 3.x: use DB version 5. Version 4.x or 5.x: use DB version 6. LimeSurvey Professional (cloud): use DB version 6.

What should I do if my LimeSurvey import created a blank survey?+

A blank survey after import usually means the wrong DB version was used. Delete the blank survey in LimeSurvey admin. Return to Pirai AI, check your LimeSurvey version (Help > About), regenerate the LSS selecting the correct DB version, and re-import. Regenerating with a different DB version takes seconds - you do not need to re-upload your document.

Which LimeSurvey DB version should I use if I am not sure of my version?+

Select DB version 6 - it covers LimeSurvey 4.x and 5.x, which account for the majority of current LimeSurvey installations worldwide. LimeSurvey 3.x is end-of-life and increasingly rare. If DB version 6 fails, check your version at Help > About LimeSurvey and regenerate with DB version 5 if you are running 3.x.
