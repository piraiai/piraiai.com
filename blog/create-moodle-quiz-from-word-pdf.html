How to Create a Moodle Quiz From a Word or PDF Document (2026)

Arun Raj•August 02, 2026•5 min read•Guide
Quick Answer

Moodle cannot open Word or PDF files directly. To create a Moodle quiz from an existing document, convert the document to AIKEN format (for MCQ only) or GIFT format (for mixed types), then import via Question bank > Import. Pirai AI generates the AIKEN .txt file automatically from any Word, PDF, or Excel document. Import it into Moodle in under 2 minutes.

Your Options for Creating a Moodle Quiz From a Document

Moodle quizzes are built from a question bank. You cannot paste or upload a Word document to create a quiz directly - you first add questions to the question bank, then build the quiz by drawing from that bank. Getting questions from a document into Moodle's question bank requires one of three approaches:

Method 1: Manual Entry in Question Bank

Go to your Moodle course. Gear menu > More > Question bank > Add > a new question. Select the question type, enter all fields, save. This is the only method that supports every Moodle question type including matching, cloze (fill-in-the-blank), calculated, random short-answer matching, and all others. Best for small additions or question types that cannot be imported via text format. Time-consuming for large question banks - 3-7 minutes per question for complex types.

Method 2: AIKEN Format Import

The simplest import route. Create a plain text .txt file in AIKEN syntax (question on one line, A. B. C. D. on separate lines, ANSWER: at the end). Import via Question bank > Import > Aiken format. Limitations: AIKEN only supports single-answer multiple choice. All other question types must be added manually. Best for: quiz banks that are entirely or mostly multiple choice.

Method 3: GIFT Format Import

GIFT supports multiple choice, true/false, short answer, numerical, matching, and essay questions. The syntax is more complex than AIKEN. Import via Question bank > Import > GIFT format. Best for: mixed question type quizzes. The challenge: GIFT requires specific syntax for each question type - incorrect syntax causes partial imports or errors without clear feedback. Writing GIFT format manually from a Word document is error-prone for large question banks.

After Import: Building the Quiz

After questions are in the question bank, create the quiz: Add an activity or resource > Quiz. Name it and configure the timing, grade settings, and question behaviour. In the quiz editor, click Add > from question bank to select which imported questions to include. You can randomise question order, set different point values per question, and add section headings. Questions imported via AIKEN come in at 1 mark each by default - adjust individual question marks in the quiz editor if your grading uses different point weights.

Frequently Asked Questions

Can I import a Word document directly into Moodle as a quiz?+

No. Moodle cannot open Word documents directly. Questions must be imported via text-based formats: AIKEN (.txt) for multiple choice, GIFT (.txt) for mixed question types, or Moodle XML. To convert a Word document, upload it to Pirai AI, select Moodle, download the AIKEN .txt, and import via Question bank > Import > Aiken format.

How do I create a quiz in Moodle from a PDF?+

Upload the PDF to Pirai AI at platform.piraiai.com, select Moodle, download the AIKEN .txt file. Import it into Moodle via Question bank > Import > Aiken format > upload file > Import. Then create a quiz activity: Add activity > Quiz > Edit quiz > Add > from question bank. For scanned PDFs, enable Advanced PDF Processing for OCR.

How long does it take to create a 40-question Moodle quiz from a Word document?+

With Pirai AI generating the AIKEN file, the question import step takes under 5 minutes. Manual entry in Moodle's question editor takes 3-4 hours for 40 multiple choice questions. Manually formatting AIKEN text from a Word document takes 45-60 minutes. After import, building the quiz activity (adding questions from the bank, configuring settings) takes an additional 10-15 minutes.

What question types can I import into Moodle from a Word document?+

AIKEN format (which Pirai AI generates) supports multiple choice questions with a single correct answer. True/false can be represented as two-option MCQ. For short answer, essay, numerical, and matching questions, use GIFT format (manual) or add questions directly in Moodle's question editor after the MCQ bulk import.
