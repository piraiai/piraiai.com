How to Import a Survey Into LimeSurvey: LSS File and Document Methods

Arun Raj•August 28, 2026•6 min read•Guide
Importing Into LimeSurvey

LimeSurvey imports surveys via LSS files - XML-based files that define the complete survey structure including question groups, questions, answer options, and survey settings. There is no direct document upload in LimeSurvey - you cannot open LimeSurvey and import a Word or PDF file. To import a survey from a document, you must first convert the document to LSS format using Pirai AI, then import the LSS via the LimeSurvey admin panel. This guide covers the full workflow.

Before You Start - DB Version

LimeSurvey LSS files use one of two database schema versions. Using the wrong version for your installation causes an import error:

  • DB version 5 - for LimeSurvey 3.x installations
  • DB version 6 - for LimeSurvey 4.x and 5.x installations (most current)

Check your version: log in to your LimeSurvey admin panel, go to Help > About LimeSurvey. The version number is displayed at the top. If you see 4.x or 5.x, select DB version 6. If you see 3.x, select DB version 5. When in doubt, DB version 6 covers most current self-hosted and LimeSurvey Professional installations.

Step 1 - Generate the LSS File From Your Document

From Word, PDF, or Excel using Pirai AI:

1. Go to platform.piraiai.com. Upload your document (Word, PDF, or Excel). For scanned PDFs, enable Advanced PDF Processing.

2. Review extracted questions in the workspace. Confirm question types and answer options.

3. Select LimeSurvey. Choose DB version 5 or 6 to match your installation.

4. Download the LSS file.

From an existing survey (LimeSurvey export): In LimeSurvey admin, open an existing survey. Go to Survey menu > Export > Export survey structure (LSS). This exports the existing survey as an LSS that can be imported into another LimeSurvey instance.

Step 2 - Import the LSS Into LimeSurvey

1. Log in to your LimeSurvey admin panel.

2. On the Surveys list page, click the + (plus) button or go to Surveys > Create a new survey.

3. In the creation options, select Import a survey (not Create a new survey).

4. Click "Choose File" and select your LSS file.

5. Click "Import survey". LimeSurvey imports all question groups, questions, and answer options from the LSS.

6. You land in the Survey settings page of the newly imported survey. Set the survey title, language, and access settings.

7. Go to the Survey structure to review imported questions before activating.

After Import - What to Configure

After the LSS import creates all questions, complete these settings in LimeSurvey:

  • Survey language: Set the primary language and add additional languages if needed (Survey settings > General > Base language)
  • Access control: Open access (public link) or token-based (closed group with invitation emails)
  • Conditions and branching: Add question display conditions using the Condition Designer for any routing logic
  • Responses: Configure data storage, response tracking, and anonymous vs identified collection
  • Notifications: Set up admin notification emails on response submission

Common Import Errors and Fixes

ErrorCause and Fix
"The file is not a valid LimeSurvey survey"File is not a valid LSS XML. Ensure the file ends in .lss and was generated for LimeSurvey, not a different survey platform.
"DB version mismatch" or import creates blank surveyWrong DB version for your LimeSurvey installation. Check your LimeSurvey version (Help > About) and regenerate the LSS with the correct DB version (5 for 3.x, 6 for 4.x/5.x).
Questions import but answer options are missingSometimes occurs with complex question types. Review in the Survey structure editor and add missing options manually.
"Maximum upload size exceeded"Large LSS files for very long surveys may exceed PHP upload limits on self-hosted installations. Increase upload_max_filesize in php.ini or split the import across multiple surveys.

Frequently Asked Questions

How do I import a survey into LimeSurvey?+

LimeSurvey imports surveys via LSS files. To import: (1) Generate an LSS file from your Word, PDF, or Excel document using Pirai AI (selecting the correct DB version for your installation), (2) Log in to LimeSurvey admin, (3) Click + > Import a survey, (4) Select your LSS file, (5) Click Import survey. All questions and answer options are created.

What is the difference between LimeSurvey DB version 5 and 6?+

DB version 5 is compatible with LimeSurvey 3.x installations. DB version 6 is compatible with LimeSurvey 4.x and 5.x. Using the wrong version for your installation causes an import error or creates a blank survey. Check your version at Help > About LimeSurvey in your admin panel.

Can I import a Word document directly into LimeSurvey?+

No. LimeSurvey only accepts LSS file imports - it cannot read Word or PDF documents directly. Use Pirai AI to convert your Word, PDF, or Excel document to LimeSurvey LSS format (selecting DB version 5 or 6 to match your installation), then import the LSS via LimeSurvey admin > + > Import a survey.

How do I check which LimeSurvey version I have?+

Log in to your LimeSurvey admin panel. Go to Help > About LimeSurvey. Your version number is displayed at the top of the About page. Version 3.x requires DB version 5. Version 4.x or 5.x requires DB version 6.
