How to Create a REDCap Instrument From a Word or PDF Document

Arun Raj•August 02, 2026•5 min read•Guide
How REDCap Import Works

REDCap does not have a survey import wizard. You cannot upload a Word document, paste questions in, or drag-and-drop content from a PDF. The only way to create a REDCap instrument from an existing document is to convert it into a Data Dictionary CSV - a structured spreadsheet that defines every field - and upload it via Project Setup > Data Dictionary > Upload File. Pirai AI generates this CSV automatically from your source document in minutes.

Why REDCap Has No Direct Document Import

REDCap organises survey content differently from other platforms. Instead of questions, it uses fields organised into instruments. Each field has a variable name, field type, field label, answer choices (for radio/checkbox/dropdown), validation rules, and optional branching logic - all defined as columns in the Data Dictionary CSV. A Word document has none of this structure, so REDCap cannot read one directly.

This means every time a researcher wants to deploy a validated instrument or clinical questionnaire in REDCap, they face a choice: build it field by field in the Online Designer (slow and error-prone for long instruments), or create the Data Dictionary CSV and upload it in bulk. Pirai AI automates that second path.

What the REDCap Data Dictionary Requires

The Data Dictionary is a CSV with specific column headers. REDCap requires these columns in order:

ColumnWhat Goes Here
Variable / Field NameUnique identifier: lowercase, underscores only. E.g. phq9_q1
Form NameInstrument name: lowercase, underscored. E.g. depression_screen
Field Typetext, notes, radio, checkbox, dropdown, calc, file, slider, yesno, truefalse, descriptive
Field LabelThe question text shown to the respondent - verbatim from your document
Choices / CalculationsFor radio/checkbox/dropdown: 1, Strongly Agree | 2, Agree | 3, Neutral | 4, Disagree | 5, Strongly Disagree
Branching LogicShow condition: e.g. [q1] = '1'
Required Field?y if the field must be completed before the form can be saved
Text Validation TypeFor text fields: date_mdy, integer, number, email, phone, etc.

Pirai AI populates every required column from your source document automatically. Variable names are generated from field labels, form names are mapped from document sections, field types are detected from question structure, and answer choices are formatted in REDCap's pipe-delimited syntax.

Three Ways to Create a REDCap Instrument

Method 1: REDCap Online Designer (Manual)

Log into REDCap, open your project, go to Project Setup > Online Designer. Click on an instrument to open it. For each field: click Add Field, select the field type, type the variable name, paste the field label, enter each answer choice, set validation and required status. Click Save. Repeat for every field.

Time estimate: 3-5 minutes per simple text or radio field. 10-15 minutes per checkbox field with many options. A 40-item validated scale: 3-4 hours. A 60-field clinical CRF: 6-8 hours. Risk: Transcription errors alter field labels - critical for validated instruments where exact wording is required for psychometric validity.

Method 2: Build the Data Dictionary CSV Manually

Download the Data Dictionary template from Project Setup > Data Dictionary > Download the current Data Dictionary. Open in Excel. Add one row per field, filling in all required columns. Save as CSV. Upload via Project Setup > Data Dictionary > Upload File > Commit Changes.

Time estimate: Similar to manual Online Designer entry. Faster for experienced REDCap users who know the column structure - still 2-4 hours for a 40-field instrument. Advantage over Method 1: Allows bulk editing in Excel and copy-paste from the source document into field label cells before formatting choice columns.

Method 3: Pirai AI Document-to-Data Dictionary Conversion

Upload your Word, PDF, or Excel document to Pirai AI. Select REDCap as the target. Review the extracted fields in the AI Survey Editor - confirm field types, variable names, and choice formatting. Download the Data Dictionary CSV. Upload it to REDCap via Project Setup > Data Dictionary > Upload File > Commit Changes.

After Uploading the Data Dictionary

After a successful Commit Changes, REDCap shows a "Changes Made Successfully" confirmation. Go to the Online Designer to review your instrument. Variable names, field types, and answer choices are all visible and editable. Add branching logic conditions in the Online Designer using the drag-and-drop logic builder - branching logic referencing specific variable names is easier to configure in the interface after the instrument structure is in place. Add field validation rules for date, integer, or numeric text fields where needed.

For multi-instrument projects, upload one instrument's Data Dictionary at a time and review in the Online Designer before uploading the next to catch any field naming conflicts early.

Frequently Asked Questions

Can I upload a Word document directly into REDCap?+

No. REDCap cannot open or import Word documents, PDFs, or Excel files directly. The only supported import route is a Data Dictionary CSV file, uploaded via Project Setup > Data Dictionary > Upload File. To create a REDCap instrument from a Word document, convert it to a Data Dictionary CSV using Pirai AI, then upload the CSV.

How do I create a REDCap Data Dictionary from a Word document?+

Upload the Word document to Pirai AI at platform.piraiai.com, select REDCap as the target, and download the Data Dictionary CSV. The CSV has all required columns populated: variable names, form names, field types, field labels, and pipe-delimited answer choices. Upload it via REDCap Project Setup > Data Dictionary > Upload File > Commit Changes.

What REDCap field types does Pirai AI support?+

Pirai AI maps source document questions to REDCap field types including: radio (single choice), checkbox (multi-select), dropdown, text (short answer with optional validation), notes (paragraph), calc (calculated field), slider (visual analog scale), yesno, truefalse, and descriptive (display text). The field type mapping is shown in the AI Survey Editor before download.

How long does it take to create a REDCap instrument from a Word document with Pirai AI?+

Under 15 minutes for most instruments, including the Pirai AI conversion step and the REDCap upload and Commit Changes step. Manual entry in the REDCap Online Designer takes 3-4 hours for a 40-field validated scale.

Can I create a REDCap instrument from a scanned PDF?+

Yes. Upload the scanned PDF to Pirai AI and enable Advanced PDF Processing for OCR text extraction. The Data Dictionary CSV is generated from the OCR-extracted content. Review field labels carefully in the AI Survey Editor before downloading - OCR on scanned documents occasionally introduces character errors that are easier to catch before upload.
