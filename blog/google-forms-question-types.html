Every Google Forms Question Type Explained (2026 Guide)

Arun Raj•July 18, 2026•3 min read•Glossary
Definition

Google Forms offers 11 question types covering basic text entry, selection, rating scales, grids, date and time, and file upload. Understanding which type to use for each measurement need is the foundation of building effective forms and surveys.

1. Short Answer

A single-line text field. Best for responses you expect to be brief: names, email addresses, numeric responses, short identifiers, or one-word answers. Google Forms validation can be added to short answer questions to enforce numeric-only responses, email format, URL format, or custom regex patterns. Use Short Answer rather than Paragraph whenever the expected response is a single word, a number, or a short phrase.

Best for: Name, email, age, job title, numeric input, ID fields.
Avoid when: You want a more than a sentence - use Paragraph instead.

2. Paragraph

A multi-line text field for open-ended free-text responses. Use Paragraph for qualitative follow-up questions, NPS or CSAT follow-ups ("What is the main reason for your score?"), feedback comments, and any question where you want a full sentence or more. Paragraph responses are the most time-consuming for respondents - limit them to no more than one or two per survey to avoid response fatigue and form abandonment.

Best for: Open-ended feedback, "why" follow-up questions, comments fields.
Avoid when: A short structured answer is sufficient - use Short Answer or a selection type instead.

3. Multiple Choice

A single-select question where respondents pick one option from a list displayed as radio buttons. The most common question type in surveys and forms. Use Multiple Choice for categorical questions with mutually exclusive options: gender, age group, job function, yes/no, satisfaction category, and any question where exactly one answer should be selected. Add an "Other" option to allow free-text entry when the option list may not be exhaustive. Multiple Choice questions can also trigger section branching - routing respondents to different parts of the form based on their selection.

Best for: Categorical data, yes/no, routing/branching questions.
Avoid when: Multiple options may apply - use Checkboxes instead.

4. Checkboxes

A multi-select question where respondents can select any number of options. Use Checkboxes for "select all that apply" questions: product features used, channels accessed, topics of interest, barriers experienced. You can set a validation rule requiring respondents to select at least N or at most N options. Note that Checkboxes data exports as a comma-separated string of selected values in a single column - if you need each selection in a separate column for analysis, pre-process the export data.

Best for: Multi-select, "all that apply," attribute selection.
Avoid when: You want respondents to select exactly one option - use Multiple Choice.

5. Dropdown

A single-select question displayed as a dropdown menu rather than a list of radio buttons. Functionally identical to Multiple Choice but takes less vertical space when the option list is long (more than 8-10 options). Use Dropdown for country selection, language selection, department lists, or any categorical question with a long option list. Dropdown cannot trigger section branching - use Multiple Choice if the question needs to route respondents to different sections.

Best for: Long option lists (countries, departments), saving vertical space.
Avoid when: The question needs to trigger branching logic - use Multiple Choice instead.

6. Linear Scale

A numeric rating scale from a minimum (0 or 1) to a maximum (2-10), displayed as radio buttons on a horizontal line with optional text labels at each end. The primary question type for Likert scales (1-5 or 1-7 with endpoint labels), NPS (0-10 with "Not at all likely" and "Extremely likely"), and satisfaction ratings. The scale can only be labelled at the endpoints - if you need a verbal label at every scale point, use Multiple Choice instead. For a battery of Likert items sharing the same scale, Multiple Choice Grid is more efficient.

Best for: Single Likert items, NPS, satisfaction ratings, simple numeric scales.
Avoid when: You need verbal labels at every scale point, or you have multiple items sharing the same scale (use Grid).

7. Multiple Choice Grid

A matrix question format displaying multiple row statements against a shared set of column options. Respondents select one option per row. The primary question type for Likert scale batteries (where multiple statements share the same agree-disagree scale), satisfaction attribute ratings, and any question where multiple items are rated on the same dimension. Enable "Require a response in each row" to ensure no items are skipped. On mobile, grids with more than 5 columns require horizontal scrolling - keep column labels short and scale points to 5 for mobile-first surveys.

Best for: Likert batteries, satisfaction attribute grids, multi-item rating questions.
Avoid when: The survey is mobile-primary with more than 5 scale points - consider splitting into individual Linear Scale questions.

8. Checkbox Grid

The multi-select version of Multiple Choice Grid. Respondents can select multiple options per row. Use for attribute association questions ("Which of the following does each brand represent?"), feature usage matrices ("Which features have you used in the past month?"), or any grid question where more than one selection per row is valid. Less common than Multiple Choice Grid in survey research but useful in product and brand research.

Best for: Attribute association, multi-select matrices, "select all that apply" in grid format.
Avoid when: You want respondents to select only one option per row - use Multiple Choice Grid.

9. Date and 10. Time

Date collects a calendar date via a date picker. Time collects a time value. Use Date for birth date, event date, appointment date, or any question requiring a structured date input. Use Time for scheduling or time-of-day questions. Both are displayed as formatted inputs that vary by the respondent's device locale. Add validation to Date questions to restrict the accepted range if required.

Best for: Birth date, event scheduling, appointment booking, date-based research questions.

11. File Upload

Allows respondents to upload files from their device to Google Drive. Requires respondents to be signed into a Google account - anonymous respondents cannot use File Upload. Files are uploaded to the form owner's Google Drive. Specify accepted file types and maximum file size in the question settings. Use for portfolio submissions, assignment uploads, evidence collection, and receipt uploads. Not appropriate for anonymous or privacy-sensitive surveys because it links each upload to the respondent's Google account.

Best for: Assignment submission, portfolio collection, evidence upload in known-respondent contexts.
Avoid when: The survey is anonymous or respondents may not have a Google account.

What Google Forms Is Missing

Google Forms is a capable free tool for basic surveys and forms, but professional survey research regularly requires question types and features that Google Forms does not support:

  • Rank order questions - asking respondents to drag and rank items by preference or importance. Google Forms has no rank order type; workarounds using numbered Multiple Choice questions produce unreliable data.
  • NPS question type - while a Linear Scale (0-10) approximates NPS, there is no native NPS type that automatically calculates Promoter/Passive/Detractor groups.
  • Constant sum / budget allocation - distributing a fixed number of points across options. Not available in Google Forms.
  • Semantic differential scales - bipolar adjective pair scales. Not available natively.
  • Slider questions - continuous drag-to-rate inputs.
  • Image choice questions - selecting from images rather than text options.
  • Drill-down / cascading dropdowns - where the second dropdown depends on the first selection.

Frequently Asked Questions

How many question types does Google Forms have?+

Google Forms has 11 question types: Short Answer, Paragraph, Multiple Choice, Checkboxes, Dropdown, Linear Scale, Multiple Choice Grid, Checkbox Grid, Date, Time, and File Upload.

Which Google Forms question type is best for a Likert scale?+

Use Linear Scale for a single Likert item (e.g. one agree-disagree statement). Use Multiple Choice Grid for a battery of Likert items sharing the same scale - this displays multiple statements as rows against a shared set of scale point columns, which is the most efficient format for multi-item Likert batteries.

Can Google Forms do a matrix question?+

Yes, through Multiple Choice Grid (single select per row) and Checkbox Grid (multi-select per row). These display multiple row statements against shared column options in a grid format. They are not as feature-rich as matrix question types in Qualtrics or REDCap - there is no row randomisation and grids are harder to read on mobile with more than 5 columns.

Which Google Forms question type can trigger branching logic?+

Only Multiple Choice and Dropdown questions can trigger section-based branching in Google Forms. All other question types route to the next section by default and cannot be used to conditionally route respondents.
