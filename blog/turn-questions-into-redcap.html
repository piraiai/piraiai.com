Turn Questions Into REDCap: Convert Any Source to a Live Survey

Arun Raj•August 13, 2026•5 min read•Guide
From Questions to REDCap

Whether your questions live in a Word document, a PDF questionnaire, an Excel spreadsheet, or a pasted text list - getting them into REDCap without manual entry requires a conversion step. Pirai AI converts any source to a Data Dictionary CSV that REDCap imports directly. Upload your source, review the output, import into REDCap. Questions in - survey built.

Turn Questions Into REDCap From Any Source

  • Word documents (.docx): Survey scripts, research instruments, questionnaire drafts. Upload directly to Pirai AI.
  • PDFs: Most REDCap instruments start as published PDF questionnaires - validated clinical scales, CRFs, patient-reported outcome measures. REDCap has no PDF import. Pirai AI extracts questions verbatim from any PDF and generates the Data Dictionary CSV. For validated instruments, verbatim extraction is critical - any wording change may require protocol amendment and ethics re-approval.
  • Excel spreadsheets (.xlsx): Question banks with answer options in columns. Pirai AI reads the first sheet.
  • Pasted text: Copy from ChatGPT, a Google Doc, an email, or any source and paste into the Pirai AI editor.
  • Qualtrics QSF: Upload an existing Qualtrics survey and convert to REDCap format.

How Pirai AI Turns Questions Into REDCap

Step 1 - Upload your source. Go to platform.piraiai.com. Upload your file or paste your questions.

Step 2 - Review in the workspace. Every extracted question appears with its detected type and answer options. Edit before export if needed.

Step 3 - Select REDCap and download. Pirai AI generates a REDCap Data Dictionary CSV - the 18-column format REDCap uses to define all project fields. Columns include Variable/Field Name, Form Name, Field Type, Field Label, Choices (pipe-delimited for radio/checkbox fields), Branching Logic, and others. The generated CSV imports directly via Project Setup > Data Dictionary.

Step 4 - Import into REDCap. REDCap project > Project Setup > Data Dictionary > Upload File > Commit Changes. REDCap imports instruments via a Data Dictionary CSV - an 18-column file that defines every field's name, type, label, and answer choices. Pirai AI generates a valid Data Dictionary CSV from any source document. After upload, click Commit Changes to apply. Review all fields in the Online Designer before collecting data.

After Importing - Configure in REDCap

  • Review all imported fields in the Online Designer - check field types, labels, and answer codes
  • Set branching logic for conditional field display using REDCap's logic syntax [field_name] = '1'
  • Configure validation rules on text fields (date, email, number, integer, phone)
  • Enable survey functionality in Project Setup > Enable Survey if collecting data via survey link
  • Add form-level permissions for multi-user projects
