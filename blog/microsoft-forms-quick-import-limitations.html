Microsoft Forms Quick Import Limitations: What It Cannot Do and How to Fix It

Arun Raj•August 02, 2026•5 min read•Guide
The Core Limitation

Microsoft Forms Quick Import supports only two question types: Multiple Choice (single and multi-select) and Open Text (short and long answer). Every other question type - Likert scales, matrix grids, NPS, Rating (stars), Ranking, File Upload, and Date - is flagged as "Unsupported question type" after import and must be created manually in the form editor. For surveys with complex question types, Quick Import handles the easy questions and leaves everything else for manual recreation.

Complete List of Quick Import Limitations

Unsupported Question Types

Quick Import flags these as "Unsupported question type" - they appear in the Start Review screen and must be recreated manually:

  • Likert scale - MS Forms' native Likert question type (multiple statements on a shared scale grid) cannot be imported. Each Likert item imports as a plain text block or is flagged.
  • Matrix / rating grid - Multi-row rating grids are not a Quick Import-supported type. Each row appears as a separate unflagged question or is flagged as unsupported depending on document formatting.
  • Net Promoter Score (NPS) - MS Forms' native NPS type (0-10 scale with standard labels) is not created by Quick Import. NPS questions import as plain text or a rough numeric scale.
  • Rating (stars) - The star rating question type is not generated by Quick Import.
  • Ranking - Drag-and-drop ranking questions cannot be imported.
  • File Upload - File upload questions are not created by Quick Import.
  • Date - Date picker questions are not generated. Date questions import as open text.

Document Formatting Requirements

Quick Import is strict about source document formatting. These formatting issues cause import failures or incorrect question mapping:

  • Questions must be listed vertically. Questions in columns, side-by-side tables, or horizontal layouts are not recognised.
  • Answer options must be on separate lines with letter or number prefixes: A. B. C. or 1. 2. 3. Options written inline (separated by commas or slashes) are not parsed as separate choices.
  • No tables. Tables in the Word document are generally skipped or imported as unformatted text.
  • No images or complex equations. Image content is skipped. Mathematical notation imports as text or is skipped.
  • File size limit: 10MB. Documents larger than 10MB fail at the upload step.
  • Word (.docx) and PDF only. Excel, CSV, plain .txt, and Google Docs links are not accepted.

Post-Import Flags

After import, Start Review shows three flag types: Missing content - content skipped entirely. Uncertain conversion - content imported but question type may be incorrect. Unsupported question type - type not supported by Quick Import. Every flagged item requires manual resolution before the form is complete.

Frequently Asked Questions

What question types does Microsoft Forms Quick Import support?+

Microsoft Forms Quick Import only supports Multiple Choice (single and multi-select) and Open Text (short and long answer) question types. Likert scales, matrix grids, NPS, Rating (stars), Ranking, File Upload, and Date questions are either flagged as Unsupported question type or imported incorrectly as open text. These must be added manually after import.

Why does Microsoft Forms say 'Unsupported question type' after import?+

Quick Import can only create Multiple Choice and Open Text questions. Any other question type in your source document - Likert, matrix, NPS, Ranking, Rating, Date - triggers an 'Unsupported question type' flag in the Start Review screen. Click the flag, note what the question should be, dismiss it, and add the correct question type manually in the form editor.

How do I import a Likert scale into Microsoft Forms?+

Quick Import cannot create the native Likert question type. After import, click Add new > More question types > Likert. Set the scale labels and add each statement as a row. Alternatively, use Pirai AI to expand the Likert battery into individual Choice questions before import, which Quick Import handles without flagging.

What file formats does Microsoft Forms Quick Import accept?+

Quick Import accepts Word (.docx) and PDF files only. Excel, CSV, plain text (.txt), and Google Docs are not supported. The file size limit is 10MB. Files larger than 10MB fail at the upload step.

How can I reduce flagged items after Microsoft Forms Quick Import?+

Use Pirai AI to pre-process your document before Quick Import. Pirai AI expands matrix and Likert questions into individual Choice questions (which Quick Import handles), structures the document to Quick Import formatting requirements, and removes non-importable elements. This reduces flagged items and post-import manual work significantly for complex surveys.
