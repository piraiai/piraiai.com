Word to LimeSurvey LSS: Convert Any Document to an LSS File

Arun Raj•August 02, 2026•5 min read•Guide
What an LSS File Is

An LSS file is LimeSurvey's native survey structure format - an XML file that encodes every question group, question, subquestion, answer option, and question type code in a survey. When you export a survey from LimeSurvey, it downloads as an LSS file. When you import a survey into LimeSurvey, you upload an LSS file. Pirai AI generates a valid LSS file from any source document - without requiring you to understand the XML structure.

What an LSS File Contains

An LSS file is structured XML with the following main elements: survey-level settings (title, language, description), question groups (the equivalent of sections or pages), individual questions (with type codes, mandatory flags, and conditions), subquestions (for matrix/array rows), and answer options (with codes and labels). All of this is expressed as nested XML tags with LimeSurvey-specific attribute names.

Creating this structure by hand - even for a moderately complex survey - is impractical without deep knowledge of LimeSurvey's XML schema. The LSS file from a 40-question survey with array questions can exceed 2,000 lines of XML. This is why converting from a Word document to LSS requires a dedicated conversion tool rather than a text editor.

Converting Word, PDF, or Excel to LSS

  1. Upload your document at platform.piraiai.com. Any format: Word (.docx), PDF (text or scanned), Excel (.xlsx), CSV, or plain text. For scanned documents, enable Advanced PDF Processing for OCR.
  2. Review in AI Survey Editor. Check question types (List/Radio for single choice, Multiple Choice for multi-select, Array for matrix/Likert, Short Free Text for open answer). Edit variable labels and answer codes if needed before download.
  3. Select LimeSurvey as the target. Choose the LSS DB version that matches your installation: version 5 for LimeSurvey 3.x, version 6 for LimeSurvey 4.x and 5.x.
  4. Download the LSS file.
  5. Import into LimeSurvey. Admin panel > click + on navigation bar > Import > Choose file > select the LSS > Import survey. All question groups and questions appear in the survey editor.

Matrix Questions in LSS

LimeSurvey's Array question type (type F) handles Likert matrices and rating grids. In LSS format, the Array question contains a set of subquestions (the row statements) and answer options (the column scale labels). Pirai AI maps matrix questions from source documents to the Array type automatically, preserving both the row content and the scale labels in the LSS output.

Note: for very complex matrix questions with differing scale points per row, Pirai AI generates individual List (Radio) questions per row rather than a single Array question - this is always accurate but loses the visual grid display. Review matrix structures in the AI Survey Editor before downloading if your instrument relies on the grid layout.

Multilingual LSS Files

LimeSurvey has strong multilingual support. When converting a multilingual instrument (one where you have question text in multiple languages), upload the primary language version first and generate the LSS. Import into LimeSurvey. Then add additional languages through LimeSurvey's Translation tool (Survey Settings > Survey languages) and fill in the translated strings. The LSS structure handles multiple language layers internally - the translation strings are added within LimeSurvey after the primary structure is imported.

LSS Import Troubleshooting

"This file is not valid LimeSurvey XML" - Usually caused by a DB version mismatch. Download the LSS for the other DB version and retry. Questions imported as wrong type - Check the question type codes in the AI Survey Editor before downloading and correct any mismatched types. Answer options missing - Occurs when the source document has ambiguous list formatting. Ensure answer options are on separate lines directly below each question in the source document. "Survey import failed" - Check that your LimeSurvey user account has the necessary permissions to import surveys (Create surveys and Super administrator rights).

Frequently Asked Questions

How do I convert a Word document to an LSS file for LimeSurvey?+

Upload the Word document to Pirai AI at platform.piraiai.com, select LimeSurvey as the target, choose the correct DB version for your installation (version 5 for LimeSurvey 3.x, version 6 for 4.x and 5.x), and download the LSS file. Import it into LimeSurvey via Admin > + button > Import.

What is the difference between an LSS file and a Word document for LimeSurvey?+

An LSS file is LimeSurvey's native XML survey format - it defines question groups, question types, answer options, and settings in a structure LimeSurvey can read directly. A Word document has no standard structure LimeSurvey can parse. You must convert the Word document to LSS before LimeSurvey can import it.

Can I create an LSS file from a PDF?+

Yes. Upload the PDF to Pirai AI, select LimeSurvey, choose DB version, and download the LSS. For scanned PDFs, enable Advanced PDF Processing for OCR. Review the extracted question structure in the AI Survey Editor before downloading to catch any OCR errors in question text.

Why does my LSS import fail in LimeSurvey?+

The most common causes are: (1) DB version mismatch - downloading version 6 LSS for a LimeSurvey 3.x installation; (2) insufficient user permissions - the importing account needs Create surveys rights; (3) corrupted LSS structure - try regenerating the LSS from Pirai AI. Check your LimeSurvey version in Admin > Global Settings > Overview to confirm which DB version to use.

Does Pirai AI generate LSS files for LimeSurvey 6?+

Yes. Pirai AI generates LSS files for both DB version 5 (LimeSurvey 3.x) and DB version 6 (LimeSurvey 4.x and 5.x). Select the correct version for your installation when downloading. Most current LimeSurvey installations are 5.x and use DB version 6.
