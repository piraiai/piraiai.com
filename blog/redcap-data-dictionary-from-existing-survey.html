Convert an Existing Survey Into a REDCap Data Dictionary

Arun Raj•August 02, 2026•5 min read•Guide
The Migration Problem

Validated research instruments, clinical questionnaires, and survey batteries rarely start their life in REDCap. They are written in Word, deployed in Qualtrics, or collected in Google Forms before a study's data management requirements necessitate migration to REDCap. Converting an existing survey to REDCap means producing a correctly structured Data Dictionary CSV - not the original document, but a field-by-field specification REDCap can read and commit to a project in one step.

Where Existing Surveys Come From

Word documents - The most common source. Published validated instruments (PHQ-9, GAD-7, SF-36, PROMIS measures), study-specific questionnaires drafted by the research team, and CRFs prepared by sponsors or CROs typically exist as Word files. Converting these to REDCap means reading the document structure and mapping question types, scale labels, and answer choices to Data Dictionary columns.

Qualtrics QSF files - Researchers who built a study in Qualtrics and now need to migrate to REDCap for HIPAA-compliant data collection or institutional data sovereignty. Qualtrics and REDCap use completely different data structures - a QSF contains question blocks and display logic while a Data Dictionary contains flat field-level definitions. Pirai AI handles this mapping automatically.

Google Forms and SurveyMonkey exports - Early-phase pilot studies often run in Google Forms or SurveyMonkey. When the study scales or data regulations require institutional infrastructure, migration to REDCap follows. Export the original form as a Word or PDF and convert.

Paper CRFs - Case Report Forms used in clinical trials often exist only as paper or scanned PDFs. Digitising them into REDCap requires OCR extraction followed by Data Dictionary generation.

REDCap Choice Formatting

For radio, checkbox, and dropdown fields, answer choices must be in REDCap's pipe-delimited format in the Choices column:

1, Not at all | 2, Several days | 3, More than half the days | 4, Nearly every day

Each option is a numeric code, comma, space, then the label. Options are separated by space-pipe-space. Pirai AI generates this format automatically from the answer options in your source document - no manual pipe-delimited formatting required.

Conversion Workflow

  1. Prepare your source. For Word documents: use the file as-is. For Qualtrics: export as QSF (Survey tab > Tools > Import/Export > Export Survey). For SurveyMonkey: export as Word or PDF. For Google Forms: download responses structure or screenshot the form questions. For scanned PDFs: scan at 300 DPI minimum for clean OCR.
  2. Upload to Pirai AI. Go to platform.piraiai.com. Upload the document. Select REDCap as the target.
  3. Review in AI Survey Editor. Confirm field types, variable names, and choice formatting. Check that matrix Likert items are assigned the correct radio type and that Matrix Group Name values group related rows together.
  4. Download the Data Dictionary CSV.
  5. Import into REDCap. Project Setup > Data Dictionary > Upload File > select CSV > Upload File > review the summary > Commit Changes.
  6. Review in Online Designer. Add branching logic, field validation rules, and calculated field formulas in the Online Designer after import.

What Requires Manual Configuration Post-Import

Branching logic: REDCap branching logic uses variable names (e.g. [diagnosis_type] = '2'). Logic from source platforms uses different syntax and QIDs that do not translate directly. Configure branching in the Online Designer's drag-and-drop logic builder after the instrument structure is in place. Calculated fields: Scoring formulas (e.g. sum of PHQ-9 items) must be entered in the Online Designer using REDCap's expression syntax. Field validation: Date, integer, and number validation rules must be applied in the Online Designer after import. Survey settings: Survey queue, auto-continue, and participant-facing survey options are configured in the Survey Settings section of each instrument.

Frequently Asked Questions

How do I convert a Qualtrics survey to REDCap?+

Export your Qualtrics survey as a QSF file (Survey tab > Tools > Import/Export > Export Survey). Upload the QSF to Pirai AI at platform.piraiai.com, select REDCap as the target, and download the Data Dictionary CSV. Import it into REDCap via Project Setup > Data Dictionary > Upload File > Commit Changes. Display logic and branching conditions require manual configuration in the REDCap Online Designer after import.

Can I convert a Google Forms survey to REDCap?+

Yes. The easiest route is to download a Word version of your Google Form content and upload it to Pirai AI. Select REDCap as the target and download the Data Dictionary CSV. Import into REDCap via Project Setup > Data Dictionary > Upload File. Google Forms does not export a document directly, so screenshot or copy your questions into a Word file first.

How are Likert scale questions handled when converting to REDCap?+

Each row of a Likert matrix becomes a separate radio field in REDCap. The scale columns become the answer choices in pipe-delimited format. To display the fields as a visual matrix in REDCap, assign the same Matrix Group Name value to all related radio fields in the Online Designer after import - REDCap renders fields with the same Matrix Group Name as a grid.

Does Pirai AI preserve exact item wording when converting to REDCap?+

Yes. Field labels in the Data Dictionary CSV are populated verbatim from the source document. This is critical for validated research instruments where the psychometric properties are established for specific item wording. Manual entry always carries transcription error risk. Pirai AI preserves the exact text from the uploaded document in every field label.
